# 例桥资料包 —— 变截面预应力混凝土连续箱梁桥（FCM · NCE2）

本目录是本 skill **全程示例桥（"例桥"）** 的完整实体资料，随 skill 发布。各 reference 文档中凡称"例桥实测 / 例桥模型"，数据**均出自此处**——例子因此自包含、可在任意全新会话查证，**不依赖 `work/` 开发场**。

## 桥梁概况
| 项 | 值 |
|---|---|
| 桥型 | 变截面预应力混凝土连续箱梁桥 |
| 跨径 | 70 + 100 + 70 m（全长 240 m）|
| 桥面全宽 | 16 m（净 14 + 2×1 m 人行道）|
| 设计荷载 | 公路-I 级；人群 3.0 kN/m² |
| 施工方法 | 悬臂浇筑（FCM，挂篮对称悬浇）|
| 主梁截面 | 单箱单室，MIDAS 截面类型 单箱多室2（`SHAPE="NCE2"`）|
| 变高 | 墩顶 6.0 m → 跨中 2.5 m（梁底抛物线）|
| 模型规模 | 节点 1–77、单元 1–76、母截面 7（3 PSC + 4 TAPERED）；钢束组 5 / 特性 2 / 钢束 172 |
| 模型单位 | **kN-m**（长度 m、力 kN）——与全 skill 文档/示例一致 |
| 预应力松弛 | **JTG18/JTG04**（`RM=2`，中国桥规范）|

## 数据出处约定
- **几何**（节点 / 截面 vSIZE / 梁高 / 壁厚）→ 设计图（本目录 .png / .pdf）判读，必要时与 `.mct` 互校。

- 截面 vSIZE 已**双源核验**（`.mct` 回读 + 设计图判读逐位对死），详见 `reference/截面库/单箱多室2-NCE2.md`。
