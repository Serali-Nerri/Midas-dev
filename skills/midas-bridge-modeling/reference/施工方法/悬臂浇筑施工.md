# 悬臂浇筑施工（FCM，Free Cantilever Method）

> 工法库的一份。讲清"悬臂浇筑这种工法在建模上特有的东西"——节段怎么分、结构组怎么对称、
> 施工阶段什么节拍、工法专属荷载、合龙体系转换。**驱动决策文档的"结构组 / 施工阶段荷载 / 施工阶段"三章。**
>
> 边界：本文给**方法骨架与缺省经验值**；确定量（材料/活载/温度/组合/限值）一律回 `reference/code/`，
> 几何（截面/节段长定值）回设计图与专项施组。规范不规定悬浇节段长度——节段划分属施工方法范畴。

---

## 1. 工法概述
墩顶 0# 块托架现浇 → 0# 块两侧对称安装挂篮，由墩顶向跨中逐节段悬臂浇筑（每段浇前挂篮前移、浇后张拉顶板束，**始终保持墩两侧对称平衡**）→ 边跨直线段支架现浇 → 先边跨、后中跨合龙 → 拆临时固结换成桥支座 → 二期 + 长期徐变。

适用：变截面预应力混凝土连续箱梁 / 连续刚构，主跨约 50–250 m。建模上的三个工法印记：**对称悬臂（结构组成对）、逐段节拍（施工阶段重复）、合龙体系转换（边界组切换）**。

---

## 2. 节段划分（决策文档"节点/截面"章的工法依据）
JTG 设计规范不管悬浇节段长度（属施工范畴）；规范层唯一硬约束是**计算跨径 L₀ = 相邻支座中心距**驱动活载/支反/制动力 → **墩心必须落节点**。

| 部位 | 缺省值（经验，非强制） | 规则 |
|---|---|---|
| 0# 块 L0 | 10 m（8–12，按墩宽放大） | 罩墩顶 + 首对挂篮起步空间 |
| 悬浇节段 | 根部 3.0–3.5 / 中部 4.0 / 跨中 4.5–5.0 | **靠墩短、靠跨中长**；根部受挂篮吊重控（湿重 ≈ A·L·26kN/m³ ≤ 挂篮吊重量级） |
| （简化）等长 | 4.0 m | 不分档折中 |
| 单悬臂节段数 n | `ceil((0.5·L_主 − L0/2 − L_合中/2)/L_段均)` | 反算 |
| 合龙段（边/中） | 2.0 m | 固定，多源一致 |
| 边跨现浇段 | `L_边 − L_边悬臂 − L_合边` | 几何反算 |
| 边中跨比 | 连续梁 0.7–0.8 / 连续刚构 0.55 | 影响边跨现浇段长与悬臂平衡 |

**必落节点**：墩心（单支座首选）、每节段端、合龙点（边/中）、端支座/桥台（主梁首末节点）、悬臂端（伸出支座外，独立节点+弹性连接+临时竖向约束）。
节点排好后跨径天然=设计跨径，`bEXACTSPAN=false` 即回正确值，勿硬写精确跨度。

## 3. 节段 ↔ 单元 ↔ 结构组（决策文档"结构组"章的工法依据）
- **1 悬浇节段 = 1 梁单元**（墩两侧对称各一）；0# 块 / 边跨现浇 / 锚固区按需细分。
- **结构组按对称分组**：每一浇筑节段以"墩两侧对称两单元"为一组，体现悬臂平衡；0# 块、边跨现浇段、合龙段单独成组。
- 全部主梁单元须被结构组无重叠、无遗漏覆盖。**结构组是边界激活与施工阶段的前置。**

> 通用骨架（N 跨 FCM 悬浇）：每墩一组 0#；每墩每节段一组（左右对称对）；边跨现浇各一组；合龙各一组。
> ⚠ 保证方法，不保证按"N 跨"盲抄数值——具体段数/单元号按本桥节段图与节点布置定。

## 4. 变高与变截面（决策文档"截面/变截面"章的工法依据）
变高箱梁只定义**支点 + 跨中两个关键截面**，变高区由**变截面组**沿程内插。
- 梁底曲线：`H(x) = H_跨中 + (H_支点 − H_跨中)·((L0 − x)/L0)^n`，n=2（抛物线），x 自跨中/合龙点起算。
- 等高区（跨中/边支/合龙/0#）用 **PSC 定截面**；变高区用 **TAPERED**（i/j 端各一组尺寸）。
- **插值阶次：梁高(z)向 2 次=抛物线、宽(y)向 1 次=线性**。编码 `ZVAR:"POLY", ZEXP:2.0, ZFROM:"i"`（i 端=跨中→斜率 0）/ 变截面 `Z_VAR:2`；一次则 `LINEAR`/`Z_VAR:1`。
- 梁单元偏心统一参考梁顶中心，变高向下生长。
- ⚠ **写入顺序**：截面(关键+变截面) → 单元(带截面指派) → **变截面组（写入校验单元号，必在单元之后）**。
- 截面 vSIZE 数组哪一位控梁高/板厚见 `reference/截面库/单箱多室2-NCE2.md`；建法见 `reference/建模模块/截面.md`。

## 5. 施工阶段节拍（决策文档"施工阶段"章的工法依据）
FCM 标准节拍（结构组/边界组/荷载组只在对应阶段激活/钝化，再现施工进程与体系转换）：

| 阶段 | 动作 | 激活 | 钝化 |
|---|---|---|---|
| CS1 | 各墩 0# 块 + 桥墩现浇、墩顶临时固结 | 0# 结构组、0# 固结边界组、自重/0#隔板/挂篮0/湿重1/顶板束0 | — |
| CS2…CSk | 逐节段对称悬臂（重复节拍） | 段 k 结构组、挂篮k/湿重k/顶板束k | 挂篮 k-1、湿重 k-1 |
| 边跨现浇 | 支架现浇边跨直线段 | 边跨现浇结构组、边支座边界组、端隔板 | — |
| 边跨合龙 | 激活合龙段单元（两侧悬臂连为连续）+ 张拉边跨束 | 合龙-边结构组、换支座边界组、边跨吊架/边跨束 | 挂篮、边跨压重 |
| 中跨合龙 | 激活中跨合龙段 + 张拉中跨束 | 合龙-中结构组、中跨吊架/中跨束/跨中隔板 | 挂篮、中跨压重 |
| 成桥 | 拆临时固结换成桥支座、二期、长期徐变 | 成桥支座/有效宽度边界组、二期恒载；末阶段 DURATION 设大值收徐变 | 全部临时、0# 固结 |

- 体系转换靠激活/钝化结构组+边界组+荷载组实现，**不动单个节点/单元**。
- 合龙段是已存在的梁单元，激活即把两侧悬臂连成连续。合龙顺序：先边跨 → 后中跨（多跨：边→次→中）。
- 混凝土加载龄期按强度达设计值取（缺省 7 d）。钢束经预应力荷载组进阶段，钢束组仅几何分族不进阶段。

## 6. 工法专属荷载（决策文档"施工阶段荷载"章的工法依据）
逐节点数值随本桥几何回 MIDAS/几何算；以下为类别与施加方式：

| 荷载 | 施加 | 说明 |
|---|---|---|
| 挂篮 | 悬臂前端节点竖向集中力（两墩两侧对称 4 点/组），逐段前移 | 单套挂篮自重；每浇一段挂篮前移一节点 |
| 混凝土湿重 | 当前悬臂前端节点 **竖向力 FZ + 偏心弯矩 MY**（湿混凝土形心纵向偏心，悬臂两侧符号相反），随节段递减 | 待浇节段体积×容重 |
| 边/中跨压重 | 合龙前对称节点竖向力 | 合龙前平衡压重 |
| 边/中跨吊架 | 合龙段节点竖向力 | 合龙吊架 |
| 横隔板 | 节点力，挂"自重"工况下各隔板组（0#/端/跨中隔板） | 箱室空腔面积×隔板厚×重度（算法见「建模模块/施工阶段荷载」§3；厚度经验初拟见下表） |

> 这些都挂"施工阶段荷载"工况（隔板挂"自重"工况），按荷载组管理，随施工阶段移动激活/钝化。

**横隔板厚度经验初拟**——JTG 3362-2018 §9.3.1 仅规定箱形截面梁桥**应设置**箱内端横隔板等设置要求，**不规定厚度**；厚度属经验量，用户给定则用给定值，未给定按下表初拟，**列表提交用户审核后方可入模**：

| 隔板 | 经验初拟规则 | 出处 |
|---|---|---|
| 0#（墩顶）隔板 | 与桥墩两壁等厚，常见 2.0–3.0 m | 中交公规院《预应力连续刚构桥总体设计及主要尺寸》 |
| 端（边支点）隔板 | 0.8–2.0 m，按边跨跨径取值 | 同上 |
| 跨中隔板 | 0.5–0.6 m（桥面宽 16 m 级；更宽适当加大，小跨径可不设） | 《沈阳大学学报(自然科学版)》2017 年第 3 期（长安大学桥隧实验室） |

> 所有横隔板均应设过人孔洞以保证箱内通道全桥贯通（构造要求）；重量计算默认按实心不扣孔（偏安全），除非用户指定扣孔。

## 7. 钢束随工法（决策文档"预应力"章的工法依据）
- **顶板束（负弯矩）**：墩顶悬臂，每节段对称布、随悬臂推进逐节张拉，锚于各节段顶。按墩分族（如顶板束-左主墩/右主墩）。
- **底板/连续束（正弯矩）**：跨中下缘抛物线，合龙后张拉。
- **合龙束 / 边跨现浇束**：合龙段与边跨现浇段。
- σcon 上限 0.75 fpk（回 3362 §6.1.3）；束数依各控制截面承载/抗裂需求由验算引擎反算（配束见 `reference/建模模块/钢束.md`，验算见 `reference/建模模块/验算.md`）。

## 8. Checklist（建模/生成器自检）
- [ ] 每墩心 1 节点；节段端/合龙点/端支座/悬臂端全部落节点。
- [ ] 1 节段=1 单元（对称各一）；结构组对称成对、无重无漏覆盖全单元。
- [ ] 变高区 TAPERED（z 二次、y 一次），只给支点+跨中关键截面；写入序 截面→单元→变截面组。
- [ ] 墩梁 RIGID 弹性连接、墩底固结、悬臂端临时竖向约束随合龙阶段边界组激活。
- [ ] PSC 支承标"单元 N 的 I 端=节点 N"（末端落末单元 J 端），核法=支承端推回节点 X=墩/台 X。
- [ ] 施工阶段：每结构组在对应浇筑阶段激活且仅一次；临时荷载及时钝化；边界组随 4 个体系转换时刻切换；末阶段收长期徐变。
- [ ] 牢记 L₀（计算跨径=支座中心距）驱动 JTG 活载——墩心可定位是前提。

## 来源与边界
- 【规范】JTG D60-2015（L₀ 驱动活载/折减/制动力）、JTG 3362-2018（§9.3.1 横隔板设置要求、§9.4.17 拼装接缝、§6.1 张拉、§7.2 施工应力）。规范不规定悬浇节段长度与横隔板厚度。
- 【官方】MIDAS《Construction Stage Analysis using FCM Bridge Wizard》（只借结构/编码，不抄其 KS 材料/CEB-FIP 徐变/无中国活载）。
- 【实测】示例桥 70+100+70 FCM 全程实建验证（节段/结构组/阶段节拍/荷载/钢束/体系转换均实测）——各部件建法（端点/JSON/实测例）见 `reference/建模模块/` 对应模块。
- 【经验】节段长度/挂篮吊重/0# 块与墩宽关系无规范统一规定，属经验/个案，须按专项施组复核。横隔板厚度经验初拟规则出处：中交公规院《预应力连续刚构桥总体设计及主要尺寸》（0#/端隔板）、《沈阳大学学报(自然科学版)》2017-03（跨中隔板，16 m 宽箱梁参数分析）。
