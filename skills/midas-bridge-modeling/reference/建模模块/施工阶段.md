# 施工阶段（建模模块）

> **流程**：编**施工阶段序列**(`/db/STAG`，逐阶段激活/钝化 结构组·边界组·荷载组)。这是把前面所有"组"串起来的**总装**。
> **★三类组都为阶段服务**：结构组(GRUP)=该阶段新成形的梁段；边界组(BNGR)=该阶段的支承/约束状态；荷载组(LDGR)=该阶段施加/撤除的荷载。阶段就是对这三类组做 **ACT(激活)/DACT(钝化)** 的时间线。
> **★硬依赖**：① 结构组(「结构组」)、边界组(「边界」)、荷载组(「施工阶段荷载」一次建齐 49 个)**必须先建**——阶段按**组名**引用；② 阶段须在**全部荷载/边界/组定义之后**；③ 整步在施工阶段分析之前。阶段分析控制 `/db/STCT` 属「分析控制」三表之一（另见该模块）。
> **★体系转换在合拢阶段**：悬臂期墩梁固结（`ACT 主墩固接`）→ 合拢时解除、激活永久支座（`DACT 主墩固接` + `ACT 边墩弹性连接/成桥`）。

## 1. API 接口
| 项 | 端点 | 说明 |
|---|---|---|
| 施工阶段 | `/db/STAG` | 阶段序列 + 各阶段 ACT/DACT 三类组 |

> 结构组 `/db/GRUP` 的建法见独立的「结构组」模块（建模次序：单元→变截面组→**结构组**→边界→…→施工阶段）；本模块只按**组名**引用它们。

## 2. JSON 各字段含义
```jsonc
// 施工阶段 /db/STAG：
{ "NAME":"张拉1#", "NO":5, "DURATION":1,        // DURATION=本阶段持续天数(驱动徐变)
  "bSV_RSLT":true, "bSV_STEP":false, "bLOAD_STEP":false, "ADD_STEP":[],
  "ACT_ELEM":[{"GRUP_NAME":"节段1","AGE":7}],    // 激活结构组(梁段成形)，AGE=激活时材龄(天)
  "ACT_BNGR":[{"BNGR_NAME":"主墩固接","POS":"DEFORMED"}],   // 激活边界组；POS=DEFORMED(变形后位置)/ORIGINAL
  "DACT_BNGR":["0#现浇"],                         // 钝化边界组(体系转换)
  "ACT_LOAD":[{"LOAD_NAME":"预应力#1","DAY":"FIRST"}],      // 激活荷载组；DAY=FIRST(阶段首日)/LAST
  "DACT_LOAD":[{"LOAD_NAME":"混凝土湿重1","DAY":"FIRST"}] }  // 钝化荷载组
}
```
> **要点**：① `ACT_ELEM.AGE`=梁段激活时的混凝土龄期（天，影响徐变加载龄期 t₀）；JTG3362 §7.2.3 张拉时强度≥80%设计值（C50 约 7 天达），故 `AGE=7`。② `DURATION`=阶段天数，是**施工进度量**（驱动该阶段徐变发展），非规范固定值，按实际工期取定。③ 钝化湿重/挂篮 = 浇筑荷载转为自重承担、挂篮前移。④ 各 ACT/DACT 的组名**必须已存在**（写前自检引用完整性）。

## 3. 映射与格式
- **施工阶段**：按 FCM 节拍展开——每节段 3 拍循环：**施工N#**(激活湿重N) → **张拉N#**(激活节段N+预应力#N，钝化湿重N) → **N#挂篮**(激活挂篮N，钝化挂篮N−1)。首尾另有 0#现浇/张拉0#、边跨现浇、边跨合拢、中跨合拢、二期恒载、长期收缩徐变。各阶段引用的**结构组**先在「结构组」模块建好（本桥 16 组）。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m，**双主墩 FCM、每墩悬臂 12 节段（左右墩对称同步浇筑）**（数据由 `GET /db/STAG` API 实测）。**施工阶段 48 个**（引用「结构组」模块所建 16 组）。

**体系转换阶段（合拢，实测）**
```json
{"Assign": {
  "43": {"NAME":"边跨合拢","NO":43,"DURATION":10,"ACT_ELEM":[{"GRUP_NAME":"边跨合拢","AGE":7}],
         "ACT_BNGR":[{"BNGR_NAME":"边墩弹性连接","POS":"DEFORMED"},{"BNGR_NAME":"边跨合拢","POS":"DEFORMED"}],
         "DACT_BNGR":["主墩固接","边跨现浇"],
         "ACT_LOAD":[{"LOAD_NAME":"边跨预应力","DAY":"FIRST"}],"DACT_LOAD":[{"LOAD_NAME":"边跨压重","DAY":"FIRST"}]},
  "46": {"NAME":"中跨合拢","NO":46,"DURATION":10,"ACT_ELEM":[{"GRUP_NAME":"中跨合拢","AGE":7}],
         "ACT_BNGR":[{"BNGR_NAME":"成桥","POS":"DEFORMED"},{"BNGR_NAME":"WZ_EW_1","POS":"DEFORMED"}],
         "DACT_BNGR":["边跨合拢"],
         "ACT_LOAD":[{"LOAD_NAME":"跨中隔板","DAY":"FIRST"},{"LOAD_NAME":"中跨预应力","DAY":"FIRST"}],
         "DACT_LOAD":[{"LOAD_NAME":"中跨压重","DAY":"FIRST"},{"LOAD_NAME":"中跨吊架","DAY":"FIRST"}]},
  "47": {"NAME":"二期恒载","NO":47,"DURATION":30,"ACT_LOAD":[{"LOAD_NAME":"二期恒载","DAY":"FIRST"}]},
  "48": {"NAME":"十年收缩徐变","NO":48,"DURATION":3650}}}
```

> 解读：**边跨合拢**`DACT 主墩固接`解除悬臂期墩梁固结、`ACT 边墩弹性连接`激活边墩支座 = 第一次体系转换；**中跨合拢**`ACT 成桥`确立永久支承体系（并激活有效宽度组 `WZ_EW_1`，见「移动荷载」）= 全桥合龙成连续梁。末阶段 `十年收缩徐变` DURATION 3650 天 = 收尾长期徐变。

**核对（API 实测 GET）**：`GET /db/STAG`=48 阶段，FCM 三拍循环、`AGE=7`、合拢阶段体系转换（DACT 主墩固接→ACT 成桥）✓。**写前自检**：所有 `ACT/DACT` 的 结构组/边界组/荷载组名均存在于 GRUP/BNGR/LDGR（结构组见「结构组」模块、16 组）。
