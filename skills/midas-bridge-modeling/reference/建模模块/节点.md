# 节点（建模模块）

> **流程**：把"节点坐标表"映射成 `/db/NODE` 的 JSON、`PUT` 进 MIDAS，再 `GET` 回读核对节点数与关键坐标。节点是单元/截面/边界/荷载的落点，最先建（单位之后）。几乎"一张表直接 PUT"，无需判断。

## 1. API 接口
| 项 | 内容 |
|---|---|
| 端点 | `/db/NODE` |
| 写入 | `PUT /db/NODE`，body = `{"Assign": {<id>: {X,Y,Z}}}` |
| 回读 | `GET /db/NODE` → `{"NODE": {<id>: {X,Y,Z}}}` |

> `PUT` 是合并写入（同 id 覆盖、不影响其它 id）；id 一律用**字符串** key。

## 2. 坐标轴约定（桥梁整体坐标系）
- **X = 纵桥向**（顺桥向，沿桥轴线，里程增大方向）
- **Y = 横桥向**（垂直桥轴的水平向）
- **Z = 竖向**（vertical，向上为正；"高度"的专业叫法是竖向）

## 3. 映射与格式
**数据来源**：决策文档「节点」章的节点表（列 `节点, X, Y, Z`，大体量随附 CSV）。

**字段映射**（表列 → JSON）：
| 节点表列 | JSON 位置 | 单位/说明 |
|---|---|---|
| 节点号 | `Assign` 的 key（字符串） | 节点 id |
| X | `X` | m，纵桥向 |
| Y | `Y` | m，横桥向 |
| Z | `Z` | m，竖向 |

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁桥，跨径 **70 + 100 + 70 m**（全长 240 m），桥面宽 16 m，悬臂浇筑（FCM）。脊柱单梁模型、**77 个梁节点（1–77）**，全部 Y=0、Z=0（建在形心参考线，截面顶对齐节点、变高靠梁底下凹）。

**① 节点表（`节点表格.csv` 片段，编码 utf-8-sig）**
```
节点,X(m),Y(m),Z(m)
1,-70,0,0
2,-68.5,0,0
3,-64.5,0,0
…
23,0,0,0
…
39,50,0,0
…
55,100,0,0
…
77,170,0,0
```

**② 真实写入请求 `PUT /db/NODE`（body）**——把 77 行全列，此处截关键节点示意：
```json
{
  "Assign": {
    "1":  {"X": -70.0,  "Y": 0.0, "Z": 0.0},
    "2":  {"X": -68.5,  "Y": 0.0, "Z": 0.0},
    "23": {"X": 0.0,    "Y": 0.0, "Z": 0.0},
    "39": {"X": 50.0,   "Y": 0.0, "Z": 0.0},
    "55": {"X": 100.0,  "Y": 0.0, "Z": 0.0},
    "77": {"X": 170.0,  "Y": 0.0, "Z": 0.0}
  }
}
```

Python（midas_civil 包，从 CSV 组装后一次 PUT）：
```python
import csv
assign = {}
with open("节点表格.csv", encoding="utf-8-sig") as f:
    for r in csv.DictReader(f):
        assign[r["节点"]] = {"X": float(r["X(m)"]), "Y": float(r["Y(m)"]), "Z": float(r["Z(m)"])}
MidasAPI("PUT", "/db/NODE", {"Assign": assign})   # 77 个节点一次写入
```

**③ 回读核对 `GET /db/NODE`（返回）**：
```json
{"NODE": {
  "1":  {"X": -70.0, "Y": 0.0, "Z": 0.0},
  …
  "77": {"X": 170.0, "Y": 0.0, "Z": 0.0}
}}
```
核对：节点数 = **77** ✓；关键控制节点 X：台0=−70 · 墩1=0 · 跨中=50 · 墩2=100 · 台3=170 ✓。

| 节点 | X(m) | 位置 |
|---|---|---|
| 1 | −70 | 台0 梁端 |
| 2 | −68.5 | 边台支座（梁端往里 1.5 m）|
| 23 | 0 | 墩1 墩心 |
| 39 | 50 | 中跨跨中（合龙段）|
| 55 | 100 | 墩2 墩心 |
| 77 | 170 | 台3 梁端 |

> 虚拟支座节点（78–89）不在节点表——它们不连梁单元、按支承几何在「边界」模块生成。
