# 收缩徐变 + 支座沉降（建模模块）

> **流程**：两组相对独立的"时间/位移"作用——
> **A 收缩徐变**（时间依存材料）：**徐变收缩函数**(`/db/TDMT`) → **材料连接**(`/db/TMAT`) → **逐单元理论厚度**(`/db/EDMP`)。
> **B 支座沉降**：**沉降组**(`/db/SMPT`) → **沉降工况**(`/db/SMLC`)。
> **★硬依赖**：① A 必按 TDMT→TMAT→EDMP 顺序，且**整步在施工阶段分析之前**（徐变随阶段累积）；② B 的 `SMPT.ITEMS` 引用**虚拟支座节点**（须先建「边界」）。
> **★规范码（致命错误）**：`TDMT.CODE` 必须 **`CHINA_JTG3362_2018`**（公路混凝土箱梁）；**误用 `CHJTG_T_D65_2015`**（钢管混凝土哑铃截面）会令徐变系数→∞、施工阶段分析出 NaN 而中止。
> **★`EDMP` 逐单元理论厚度（GUI 优先）**：变截面各单元 `h=2A/u` 沿桥变化，**优先 GUI 自动生成**（特性→修改特性→「构件的理论厚度」+「中国标准」→全选单元应用，MIDAS 逐元算）；API 写入为可选（`h` 须回 SECTIONALL 取 A/u，taper 单元 MIDAS 不逐元暴露 A/u，纯自算约 1% 偏差，故 **API 路径建议仅用于核验**或棱柱段）。

## 1. API 接口
| 项 | 端点 | 说明 |
|---|---|---|
| 徐变收缩函数 | `/db/TDMT` | 规范+湿度+龄期+理论厚度兜底 |
| 时变材料连接 | `/db/TMAT` | 把徐变函数连到结构材料 |
| 逐单元理论厚度 | `/db/EDMP` | 每单元 `h=2A/u`（按截面变化）|
| 沉降组 | `/db/SMPT` | 每支座一组（虚拟支座节点对 + 沉降量）|
| 沉降工况 | `/db/SMLC` | 选组 + 同时沉降组数上下限（包络）|

## 2. JSON 各字段含义
```jsonc
// A1 徐变收缩 /db/TDMT：
{ "NAME":"C50", "CODE":"CHINA_JTG3362_2018",   // ★规范码：箱梁必用此；勿用 CHJTG_T_D65_2015
  "STR":50000,     // C50 抗压强度，随 /db/UNIT：kN-m→50000(kN/m²)，N-mm→50(N/mm²)
  "HU":70,         // 相对环境湿度 %
  "AGE":3,         // 收缩起始龄期(天)，JTG3362 附录C
  "BSC":5,         // 水泥种类系数(普通硅酸盐水泥=5)
  "FLYASH":0,      // 粉煤灰掺量 %
  "MSIZE":0.7466 } // 构件理论厚度兜底(随 UNIT，m)；仅对无 EDMP 覆盖的单元生效
// A2 材料连接 /db/TMAT：
{ "TDMT_NAME":"C50", "TDME_NAME":"" }   // ★TDME_NAME:"" 必须显式给(PUT 漏掉会静默失败、回读空)
// A3 逐单元理论厚度 /db/EDMP（按单元 id）：
{ "TYPE":"NSM", "H_VS":0.651 }          // NSM=理论厚度法；H_VS = 2A/u(随 UNIT，m)
// B1 沉降组 /db/SMPT：
{ "NAME":"主1", "SETTLE":-0.015, "ITEMS":[87,89] }   // SETTLE 随 UNIT(m)，负=下沉；ITEMS=虚拟支座节点对(±Y两点)
// B2 沉降工况 /db/SMLC：
{ "NAME":"沉降", "FACTOR":1, "MIN":1, "MAX":4,        // MIN~MAX=同时沉降的组数下/上限，搜最不利包络
  "ST_GROUPS":["主1","主2","边1","边2"] }              // 参与的沉降组(逐字匹配 SMPT.NAME)
```
> **要点**：① `TDMT.STR`、`MSIZE`、`EDMP.H_VS`、`SMPT.SETTLE` 都是**带量纲量**——按当前 `/db/UNIT` 取值（核心准则 2；本例 kN-m）。② `EDMP` **逐单元生效**：MIDAS 按各单元 `H_VS` 算徐变，`TDMT.MSIZE` 只兜底无覆盖单元。③ `SMPT.ITEMS` 是**虚拟支座节点对**（非脊柱节点）——强制位移经刚性弹性连接传到主梁。

## 3. 映射与格式
- **A 收缩徐变**：① TDMT 一条（主梁混凝土 C50）：规范码固定 `CHINA_JTG3362_2018`，`STR/HU/AGE/BSC` 按 JTG3362 附录C + 环境取（回决策文档「收缩徐变」与规范）。② TMAT 一条把它连到主梁材料。③ EDMP 逐单元 `H_VS`：优先 GUI 生成，API 核验。
- **B 支座沉降**：① 每个支座一沉降组 `SMPT`，`ITEMS`=该支座的虚拟节点对，`SETTLE`=规范沉降量（主墩/边墩差异化）。② 一个 `SMLC` 工况纳入全部组，`MIN/MAX` 控制同时沉降组合范围（搜包络）。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（数据由 `GET /db/*` API 实测；例子 kN-m——核心准则 2）。主梁 C50，墩顶沉降 15 mm、台顶 10 mm。

**① 徐变收缩 `/db/TDMT` + 材料连接 `/db/TMAT`**
```json
{"Assign": {"1": {"NAME":"C50","CODE":"CHINA_JTG3362_2018",
  "STR":50000,"HU":70,"AGE":3,"BSC":5,"FLYASH":0,"MSIZE":0.7466}}}
```
```json
{"Assign": {"1": {"TDMT_NAME":"C50","TDME_NAME":""}}}
```

**② 逐单元理论厚度 `/db/EDMP`（76 单元；H_VS=2A/u，随截面变化）**
```json
{"Assign": {"1":{"TYPE":"NSM","H_VS":0.651}, "2":{"TYPE":"NSM","H_VS":0.615},
            "3":{"TYPE":"NSM","H_VS":0.580}, "...":{}, "76":{"TYPE":"NSM","H_VS":0.651}}}
```
> H_VS 实测：台端≈0.651、跨中≈0.580、墩顶≈1.005（m），对称分布。**优先 GUI 自动生成**（taper 段 A/u 逐元变化、MIDAS 内部精确积分）；API 路径 `h=2A/u` 的 A/u 须回 `POST /post/TABLE`(SECTIONALL，`u=Peri_Out+0.5·Peri_In`)，**不手算箱梁几何**（核心准则 1）。

**③ 支座沉降 `/db/SMPT` + `/db/SMLC`**
```json
{"Assign": {
  "1":{"NAME":"主1","SETTLE":-0.015,"ITEMS":[87,89]},
  "2":{"NAME":"主2","SETTLE":-0.015,"ITEMS":[79,81]},
  "3":{"NAME":"边1","SETTLE":-0.01, "ITEMS":[78,82]},
  "4":{"NAME":"边2","SETTLE":-0.01, "ITEMS":[83,88]}}}
```
```json
{"Assign": {"1":{"NAME":"沉降","DESC":"","FACTOR":1,"MIN":1,"MAX":4,
  "ST_GROUPS":["主1","主2","边1","边2"]}}}
```

**④ 核对（API 实测 GET）**：`GET /db/TDMT` `CODE=CHINA_JTG3362_2018`、`STR=50000`、`HU=70`、`AGE=3` ✓；`GET /db/TMAT` `TDMT_NAME=C50`（`TDME_NAME` 回读省略空字段属正常）✓；`GET /db/EDMP`=76 单元 `NSM`，H_VS 端点 0.651/0.580/1.005 对称 ✓；`GET /db/SMPT`=4 组（主−0.015 / 边−0.01 m）、`GET /db/SMLC` `MIN/MAX=1/4`、4 组齐 ✓。
