# 单元（建模模块）

> **流程**：建**梁单元**（`/db/ELEM`，每单元两节点 + 指派母截面）→ 对**变高悬臂段**建**变截面组**（`/db/TSGR`，把整段按抛物线插值梁高）。
> **★硬依赖**：① 母截面（含变截面）**必在单元之前**——单元创建即引用 `SECT` id；② **变截面组(TSGR) 必在单元之后**——它按单元号校验；③ 节点先于单元。
> **★为什么要 TSGR**：把一个变高母截面（如 §5 跨中→支座）**整段**指派给十几个单元后，MIDAS 默认会让**每个单元各自**从 I 端渐变到 J 端（全程 1.7→5.2 m）——错。`TS-GROUP` 把整段重定义为**一条抛物线**，按各单元位置取对应梁高。**变高（Z_VAR=2）段必须配 TSGR；等高（Z_VAR=1）段单元即可，不建组。**

## 1. API 接口
| 项 | 内容 |
|---|---|
| 端点 | `/db/ELEM`（梁单元）　+　`/db/TSGR`（变截面组 = Tapered Section Group）|
| 写入 | `PUT /db/ELEM` body=`{"Assign":{<id>:{TYPE,MATL,SECT,ANGLE,NODE}}}`<br>`PUT /db/TSGR` body=`{"Assign":{<id>:{NAME,ELEMLIST,ZVAR,ZEXP,ZFROM,ZDIST,YVAR,YFROM}}}` |
| 回读 | `GET /db/ELEM` → `{"ELEM":{<id>:{…,"NODE":[i,j,0,0,0,0,0,0]}}}`<br>`GET /db/TSGR` → `{"TSGR":{<id>:{…}}}` |

## 2. JSON 各字段含义
```
# —— /db/ELEM（梁单元）——
{ "TYPE": "BEAM",     # 单元类型；梁=BEAM
  "MATL": 1,          # 材料 id（→「材料」模块）
  "SECT": 3,          # 母截面 id（→「截面」模块；变截面也是按 id 引）
  "ANGLE": 0,         # Beta 角(绕轴扭转)，正交直桥=0
  "NODE": [1, 2] }    # 两端节点 [iN1, iN2]，单元方向 i→j

# —— /db/TSGR（变截面组）——
{ "NAME": "左边跨悬臂",      # 组名
  "ELEMLIST": [8,…,20],     # 本组单元号清单（连续段）
  "ZVAR": "POLY",           # 高(z)变化律：POLY=多项式 / LINEAR=线性
  "ZEXP": 2.0,              # POLY 的指数；2=抛物线（FCM 梁底）
  "ZFROM": "i",             # 抛物线顶点(零斜率/最浅)所在端：i 或 j —— 取**浅端**(跨中侧)
  "ZDIST": 0,              # 顶点偏移(一般 0)
  "YVAR": "LINEAR",         # 宽(y)变化律；本桥宽恒 16 m → LINEAR(无变化)
  "YFROM": "i" }            # y 参考端(LINEAR 下无实义)
```
> **要点**：① `GET /db/ELEM` 的 `NODE` **补零成 8 位** `[i,j,0,0,0,0,0,0]`，核对取 `nd[:2]`。② MCT 文本里 `ZVAR` 写 **`QUADRATIC`**，MAPI JSON 写 **`POLY` + `ZEXP=2`**（同一回事）。③ `ELEMLIST` 在 JSON 里是**显式单元号数组**（MCT 简写 `8to20`）。

## 3. 映射与格式
- **单元**：连续梁里 **单元 k = 节点 k→节点 k+1**（N 节点 → N−1 单元）。每个单元的 `SECT` 按**几何分区**取母截面（决策文档「单元」表给出：单元号段 → 母截面 id）。`MATL` 全梁同一主梁材料。
- **变截面组**：只对 **Z_VAR=2 的变高悬臂段**建；**一段悬臂一组**，`ZVAR="POLY"`、`ZEXP=2`（梁底抛物线）、`ZFROM=浅端(跨中侧)`、`YVAR="LINEAR"`。等高段（Z_VAR=1，本桥 §4/§7 各单元）与等截面段（§1/§2/§3）**不建组**。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（节点 1–77、单元 1–76、母截面 1–7；数据由 `GET /db/ELEM`·`/db/TSGR` API 实测）。

**单元→母截面 分区（13 段，几何决定）**

| 单元段 | 母截面 | 含义 |
|---|---|---|
| 1 | §3 边跨墩 | 左台端等截面 |
| 2 | §4 边跨-跨中(等高) | 过渡(单元，无组) |
| 3–7 | §2 跨中 | 左边跨等截面 |
| **8–20** | §5 跨中-支座(变高) | **左主墩悬臂↑（TSGR 组1）** |
| 21–24 | §1 支座 | 左主墩顶等截面 6.0 m |
| **25–37** | §6 支座-跨中(变高) | **左主墩悬臂↓（TSGR 组2）** |
| 38–39 | §2 跨中 | 主跨跨中等截面 |
| **40–52** | §5 跨中-支座(变高) | **右主墩悬臂↑（TSGR 组3）** |
| 53–56 | §1 支座 | 右主墩顶等截面 6.0 m |
| **57–69** | §6 支座-跨中(变高) | **右主墩悬臂↓（TSGR 组4）** |
| 70–74 | §2 跨中 | 右边跨等截面 |

**变截面组（4 段变高悬臂，`.mct` 实测）**

| id | 组名 | 单元 | ZVAR | ZEXP | ZFROM |
|---|---|---|---|---|---|
| 1 | 左边跨悬臂 | 8–20 | POLY | 2 | i |
| 2 | 主跨左悬臂 | 25–37 | POLY | 2 | j |
| 3 | 主跨右悬臂 | 40–52 | POLY | 2 | i |
| 4 | 右边跨悬臂 | 57–69 | POLY | 2 | j |

> `ZFROM` 取**浅端**：§5(I=跨中浅→J=支座深)的悬臂段顶点在 **i**；§6(I=支座深→J=跨中浅)顶点在 **j**。

**③ Python 驱动（从决策文档「单元」表批量建；`MidasAPI` 约定同「节点」模块）**
```python
# 单元：连续梁 节点 k→k+1；SECT 按几何分区表 (起单元, 止单元, 母截面id)
zones = [(1,1,3),(2,2,4),(3,7,2),(8,20,5),(21,24,1),(25,37,6),(38,39,2),
         (40,52,5),(53,56,1),(57,69,6),(70,74,2),(75,75,7),(76,76,3)]
elem = {}
for a, b, sec in zones:
    for k in range(a, b + 1):
        elem[k] = {"TYPE":"BEAM","MATL":1,"SECT":sec,"ANGLE":0,"NODE":[k, k+1]}
MidasAPI("PUT", "/db/ELEM", {"Assign": elem})            # 76 单元

# 变截面组：只对 4 段变高悬臂(Z_VAR=2)；★必在单元之后
groups = [("左边跨悬臂",8,20,"i"), ("主跨左悬臂",25,37,"j"),
          ("主跨右悬臂",40,52,"i"), ("右边跨悬臂",57,69,"j")]
tsgr = {}
for i, (nm, a, b, zf) in enumerate(groups, 1):
    tsgr[i] = {"NAME":nm, "ELEMLIST":list(range(a, b+1)),
               "ZVAR":"POLY", "ZEXP":2.0, "ZFROM":zf, "ZDIST":0,
               "YVAR":"LINEAR", "YFROM":"i"}    # YVAR=LINEAR 时 YFROM 无实义，恒 "i"
MidasAPI("PUT", "/db/TSGR", {"Assign": tsgr})            # 4 组
```

**④ 回读核对 `GET /db/ELEM` / `GET /db/TSGR`（API 实测；topkey `ELEM`/`TSGR`）**
```json
{"ELEM": {"1":{"TYPE":"BEAM","MATL":1,"SECT":3,"NODE":[1,2,0,0,0,0,0,0],"ANGLE":0,"STYPE":0},
          "8":{"TYPE":"BEAM","MATL":1,"SECT":5,"NODE":[8,9,0,0,0,0,0,0],"ANGLE":0,"STYPE":0}, …}}
{"TSGR": {"1":{"NAME":"左边跨悬臂","ELEMLIST":[8,9,…,20],"ZVAR":"POLY","ZEXP":2,"ZFROM":"i","ZDIST":0,"YVAR":"LINEAR","YFROM":"i"},
          "2":{"NAME":"主跨左悬臂","ELEMLIST":[25,…,37],"ZVAR":"POLY","ZEXP":2,"ZFROM":"j", …}, …}}
```
> GET `ELEM` 回读比 PUT 多 `STYPE`（截面类型标志，普通梁=0）、且 `NODE` **补零成 8 位**（核对取 `nd[:2]`）。

核对：76 个 BEAM 单元 ✓（单元 k 接 `NODE[:2]=[k,k+1]`）；末单元 76 接 [76,77] ✓；4 个变截面组、单元清单 `8–20 / 25–37 / 40–52 / 57–69` 与 §5/§6 变高段一一对应、`ZFROM` 组1=i 组2=j ✓。
