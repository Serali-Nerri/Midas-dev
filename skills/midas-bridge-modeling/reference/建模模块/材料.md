# 材料（建模模块）

> **流程**：每种材料只给两样——**规范字符串 STANDARD + 数据库牌号 DB**，MIDAS 规范库自动解析弹模/容重/强度等，`PUT /db/MATL` 即可。**勿凭记忆猜规范名**（规范字符串与可用牌号查 §3 的表，错写会解析失败或取错值）。

## 1. API 接口
| 项 | 内容 |
|---|---|
| 端点 | `/db/MATL` |
| 写入 | `PUT /db/MATL`，body = `{"Assign": {<id>: {材料定义}}}` |
| 回读 | `GET /db/MATL` → `{"MATL": {<id>: {…含解析出的 ELAST}}}` |

## 2. JSON 各字段含义
```
{
  "TYPE": "CONC",            # 材料类型：CONC=混凝土 / STEEL=钢材·钢束
  "NAME": "C50",            # 材料名（自定，建议同牌号）
  "DAMP_RAT": 0.05,         # 阻尼比（动力/特征值分析用；混凝土惯例 0.05、钢 0.02）
  "PARAM": [ {              # 材料参数（取 [0]）
    "P_TYPE": 1,            # 1=数据库材料(DB，规范库自动解析) / 2=用户自定义(须自给E/容重…)
    "STANDARD": "JTG3362-18(RC)",  # 规范字符串（见 §3 查表）
    "CODE": "",            # 留空
    "DB": "C50",           # 数据库牌号（见 §3 查表）
    "bELAST": false,       # false=用 DB 解析的弹模；true=用户覆盖 ELAST
    "ELAST": 34500000      # 弹性模量(kN-m→kN/m²)——★PUT 时不必给，DB 自动解析；GET 回读才有。单位相关(见 §4 注)
  } ]
  # 其余 HE_SPEC/HE_COND/PLMT/P_NAME/bMASS_DENS：热/质量相关，DB 材料默认 0/false，一般不动
}
```
> **★方法要点**：DB 材料（`P_TYPE=1, bELAST=false`）**PUT 只需 TYPE/NAME/STANDARD/DB**，**不写 ELAST/容重**——这些由规范库按 STANDARD+DB 解析。GET 回读才看到解析出的 `ELAST`。

## 3. 规范字符串 × 数据库牌号 查表（写材料只需对这两样）
| STANDARD | 类型 | 可用 DB 牌号 |
|---|---|---|
| `JTG3362-18(RC)` | 混凝土 | `C25`…`C80`（C25 起每级 +5）|
| `JTG04(RC)` | 混凝土 | `C15`…`C80` |
| `JTG3362-18(S)` | 钢材/钢束 | `Strand1720` `Strand1860` `Strand1960` `Wire1470…1860` `Steelbar785/930/1080` |
| `JTG04(S)` | 钢材/钢束 | `Strand1470…1860` `Wire…` `Steelbar540/785/930` |
> 换其它规范/牌号前，先确认该串与牌号在 MIDAS 库中存在（包源 `_material.py` 的 Literal，或临时写入回读 E 验证）。完整取值层见 `reference/code_tables.md`。

## 4. 映射与格式
**数据来源**：决策文档「材料」章的材料表（列 `材料号, 部位, STANDARD, DB`）。
**字段映射**：材料号→`Assign` key；部位/牌号→`NAME`；STANDARD→`PARAM[0].STANDARD`；DB→`PARAM[0].DB`；类型(混凝土/钢)→`TYPE`。
> **★ELAST 单位相关**：本 skill 全程 **kN-m → C50 `ELAST=34500000`（kN/m²）**；N-mm 下则 `=34500`（MPa）。**PUT 不给 ELAST 即无此问题**（DB 自动解析）；回读核对 E 时按当前 `/db/UNIT`。

## 5. 例子
**例桥**：变截面预应力混凝土连续箱梁桥，跨径 70+100+70 m。**桥墩不建实体**（虚拟支座节点 + RIGID 弹性连接等效）→ **模型只有 2 种材料**：主梁 C50、预应力钢束 Strand1860（无单列 C40）。普通钢筋 HRB400 属待验算层，以钢筋码挂在混凝土材料上（见「验算」模块），不单列 MATL。

**① 真实写入请求 `PUT /db/MATL`（body）**——只给 STANDARD+DB，不给 ELAST：
```json
{
  "Assign": {
    "1": {"TYPE": "CONC",  "NAME": "C50",        "DAMP_RAT": 0.05,
          "PARAM": [{"P_TYPE": 1, "STANDARD": "JTG3362-18(RC)", "CODE": "", "DB": "C50"}]},
    "2": {"TYPE": "STEEL", "NAME": "Strand1860", "DAMP_RAT": 0.02,
          "PARAM": [{"P_TYPE": 1, "STANDARD": "JTG3362-18(S)",  "CODE": "", "DB": "Strand1860"}]}
  }
}
```
Python（midas_civil 包）：
```python
MidasAPI("PUT", "/db/MATL", {"Assign": {
  "1": {"TYPE": "CONC",  "NAME": "C50",        "DAMP_RAT": 0.05,
        "PARAM": [{"P_TYPE": 1, "STANDARD": "JTG3362-18(RC)", "CODE": "", "DB": "C50"}]},
  "2": {"TYPE": "STEEL", "NAME": "Strand1860", "DAMP_RAT": 0.02,
        "PARAM": [{"P_TYPE": 1, "STANDARD": "JTG3362-18(S)",  "CODE": "", "DB": "Strand1860"}]},
}})
```

**② 回读核对 `GET /db/MATL`（API 实测，kN-m → ELAST 为 kN/m²）**：
```jsonc
{"MATL": {
  "1": {"TYPE":"CONC", "NAME":"C50",        "DAMP_RAT":0.05, "bMASS_DENS":false, "HE_SPEC":0,"HE_COND":0,"PLMT":0,"P_NAME":"",
        "PARAM":[{"P_TYPE":1,"STANDARD":"JTG3362-18(RC)","CODE":"","DB":"C50",        "bELAST":false,"ELAST":34500000}]},
  "2": {"TYPE":"STEEL","NAME":"Strand1860", "DAMP_RAT":0.02, "bMASS_DENS":false, "HE_SPEC":0,"HE_COND":0,"PLMT":0,"P_NAME":"",
        "PARAM":[{"P_TYPE":1,"STANDARD":"JTG3362-18(S)", "CODE":"","DB":"Strand1860","bELAST":false,"ELAST":195000000}]}
}}
```
核对：材料数=2 ✓；C50 `ELAST=34500000` kN/m²（=3.45×10⁴ MPa，JTG3362-2018 表3.1.5）✓；Strand1860 `ELAST=195000000` kN/m²（=1.95×10⁵ MPa，§3.2.4）✓。
> GET 比 PUT 多回 `HE_*/PLMT/P_NAME/bMASS_DENS` 等默认字段（PUT 可省）。N-mm 模型下 `ELAST` 则为 34500 / 195000 MPa——回读按当前 `/db/UNIT` 核（核心准则 2）。
