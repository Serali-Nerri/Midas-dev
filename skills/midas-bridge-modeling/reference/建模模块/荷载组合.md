# 荷载组合（建模模块）

> **流程**：把各效应（恒载/钢束/徐变收缩二次/沉降/温度/汽车/人群）按 **JTG D60** 分项与组合系数，组合成**承载能力极限状态**（基本组合）+ **正常使用极限状态**（标准/频遇/准永久）。端点 `/db/LCOM-CONC`。
> **★两条路径（GUI 优先，与有效宽度同理）**：
> - **默认 = GUI 自动生成**：荷载组合对话框 → **混凝土设计** 页 → **自动生成** → 选**设计规范（JTG）** → 生成。MIDAS 按规范把全部组合（含分项系数）一次建好。**应优先提示用户在 GUI 完成此步**。
> - **可选 = API 写入（fallback）**：用户声明走 API 时，按 JTG D60 系数构造各组合，`PUT /db/LCOM-CONC`。
> **★组合系数是确定量**：分项/组合值系数（1.2 恒、1.4 活、0.4/0.7 准永久/频遇…）一律回 JTG D60（核心准则 1），不臆造；GUI 自动生成即应用规范系数。
> **★硬依赖**：在荷载、移动荷载、分析控制都就绪、且分析已跑出各效应结果之后（组合引用分析结果工况）。

## 1. API 接口
| 项 | 内容 |
|---|---|
| 端点 | `/db/LCOM-CONC`（混凝土设计荷载组合）|
| 写入 | `PUT /db/LCOM-CONC`，body=`{"Assign":{<id>:{NO,NAME,ACTIVE,vCOMB,…}}}`（fallback）|
| 回读 | `GET /db/LCOM-CONC` → `{"LCOM-CONC":{<id>:{…}}}` |
| 极限状态 `ACTIVE` | `STRENGTH`=承载能力(基本) / `SERVICE`=标准 / `FREQUENCY`=频遇 / `QPERMNENT`=准永久 |

## 2. JSON 各字段含义
```jsonc
{ "NO":1, "NAME":"基本1",
  "ACTIVE":"STRENGTH",       // 极限状态/组合类型(见上表)
  "bCB":true, "iTYPE":0, "iSERV_TYPE":0,
  "DESC":"基本组合(永久荷载): 0.5SM[1]+1.2(cD)+1.2(cTS)+1.0(cCR)+1.0(cSH)",  // 人读说明
  "vCOMB":[                  // 参与项：每项=(分析类型, 工况名, 系数)
    {"ANAL":"SM","LCNAME":"沉降","FACTOR":0.5},        // ANAL: SM=沉降 / CS=施工阶段结果 / MV=移动荷载
    {"ANAL":"CS","LCNAME":"恒荷载","FACTOR":1.2},
    {"ANAL":"CS","LCNAME":"钢束二次","FACTOR":1.2},
    {"ANAL":"CS","LCNAME":"徐变二次","FACTOR":1.0},
    {"ANAL":"CS","LCNAME":"收缩二次","FACTOR":1.0} ] }
```
> **要点**：① `vCOMB[].ANAL` 指**分析结果类型**——`SM`(支座沉降包络)、`CS`(施工阶段后处理出的 恒荷载/钢束一次·二次/徐变二次/收缩二次)、`MV`(移动荷载 汽车/人群)；`LCNAME` 须与这些结果工况名一致。② **承载能力组合只取钢束二次**（一次预应力计入抗力侧不组合）；**正常使用组合 钢束一次+二次都取**。③ 系数即 JTG D60 分项/组合值系数。

## 3. 映射与格式
- **组合类型（JTG D60-2015）**：
  - **承载能力·基本组合**（`STRENGTH`）：γG·恒 + γQ·活——恒 1.2、钢束二次 1.2、徐变/收缩二次 1.0、沉降 0.5、汽车/人群 1.4。
  - **正常使用·标准组合**（`SERVICE`）：各项 ×1.0（特征值）。
  - **正常使用·频遇组合**（`FREQUENCY`）：恒 1.0 + 活×频遇系数 ψf。
  - **正常使用·准永久组合**（`QPERMNENT`）：恒 1.0 + 活×准永久系数 ψq（人群 0.4）。
- 汽车/人群、最不利布载由移动荷载分析自动取包络；组合按"主导可变荷载 + 其余伴随"展开多个（故组合数多）。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（数据由 `GET /db/LCOM-CONC` API 实测）。GUI 按 JTG 自动生成 **77 个组合**：承载能力(STRENGTH) 32 + 标准(SERVICE) 15 + 频遇(FREQUENCY) 15 + 准永久(QPERMNENT) 15。

**各类组合代表（API 实测 GET）**
```jsonc

{"NO":2,"NAME":"基本2","ACTIVE":"STRENGTH","vCOMB":[
  {"ANAL":"SM","LCNAME":"沉降","FACTOR":0.5},{"ANAL":"CS","LCNAME":"恒荷载","FACTOR":1.2},
  {"ANAL":"CS","LCNAME":"钢束二次","FACTOR":1.2},{"ANAL":"CS","LCNAME":"徐变二次","FACTOR":1.0},
  {"ANAL":"CS","LCNAME":"收缩二次","FACTOR":1.0},{"ANAL":"MV","LCNAME":"汽车","FACTOR":1.4}]}

  {"ANAL":"CS","LCNAME":"钢束一次","FACTOR":1},{"ANAL":"CS","LCNAME":"钢束二次","FACTOR":1},
```

**API fallback 写入示例 `PUT /db/LCOM-CONC`**
```json
{"Assign": {"1": {"NO":1,"NAME":"基本1","ACTIVE":"STRENGTH","bCB":true,"iTYPE":0,
  "DESC":"基本组合(永久荷载)",
  "vCOMB":[{"ANAL":"SM","LCNAME":"沉降","FACTOR":0.5},{"ANAL":"CS","LCNAME":"恒荷载","FACTOR":1.2},
           {"ANAL":"CS","LCNAME":"钢束二次","FACTOR":1.2},{"ANAL":"CS","LCNAME":"徐变二次","FACTOR":1.0},
           {"ANAL":"CS","LCNAME":"收缩二次","FACTOR":1.0}]}}}
```
> 优先让用户走 GUI 自动生成（一次按规范出全部 77 组合、系数不会错）；API fallback 仅在程序化需要时用，且系数仍须逐项对 JTG D60 核对。

**核对（API 实测 GET）**：`GET /db/LCOM-CONC`=77 组合，`ACTIVE` 分布 STRENGTH 32 / SERVICE 15 / FREQUENCY 15 / QPERMNENT 15 ✓；基本组合 恒 1.2、汽车/人群 1.4、沉降 0.5；准永久 人群 0.4 ✓（JTG D60 系数）。
