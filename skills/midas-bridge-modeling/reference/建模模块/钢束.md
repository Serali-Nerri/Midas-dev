# 钢束（建模模块 · S11 待验算层·配束）

> **定位**：待验算层第一步——**反算初拟预应力钢束并建进 MIDAS**（钢束影响弹性内力，必须真建），之后 S13「验算」按 CDN 表迭代调束。**配束配筋 = 本模块（钢束）+「验算」§4-5 的普通钢筋/箍筋（`/db/RPSC`）**。
> **流程**：反算束数/线形 → **钢束组**(`/db/TDGR`) → **钢束特性**(`/db/TDNT`：类型/股数/管径/松弛/摩擦/回缩) → **钢束形状**(`/db/TDNA`：组+特性+经过单元+线形) → **张拉力**(`/db/TDPL`)。
> **★硬依赖**：① 预应力**工况 + 预应力#N 荷载组**先建（「施工阶段荷载」已占位）；钢束经预应力荷载组进施工阶段；② 单元先建（`ELEM` 引用单元号）；③ 反算需先有内力包络。
> **★单位**：量纲随当前 `/db/UNIT`（核心准则 2）；**wobble k 是 1/长度**——kN-m 下 `WF=0.0015`(/m)，N-mm 下 ÷1000，**最易踩**。

## 1. API 接口
| 项 | 端点 | GUI 对应 |
|---|---|---|
| 钢束组 | `/db/TDGR` | 钢束组（按位置/批次分族）|

## 2. 钢束特性 `/db/TDNT` — 字段全解（GUI「钢束特性值」对话框）
```jsonc
{ "NAME":"顶板束19-Φ15.2",
  "TYPE":"INTERNAL", "LT":"POST",   // ★钢束类型：INTERNAL+PRE=内部(先张)/INTERNAL+POST=内部(后张)/EXTERNAL(+POST)=外部
  "MATL":2,                          // 钢束材料 id（Strand1860）
  "AREA":0.00266,                    // 钢束总(净)面积——GUI 可由 标准(ASTM)/直径(15.2)/股数(19) 算，API 直接存面积
  "D_AREA":0.09,                     // ★导管直径(不是面积！m)
  "ASB":0.006, "ASE":0.006,          // 锚具变形/钢筋回缩/接缝压缩值 始/末(6 mm)
  "bBONDED":true, "ALPHA":0,         // 粘结类型(true=粘结)；ALPHA=体外索弯矩放大(内部束=0)
  // —— 松弛 + 强度 + 摩擦 —— ★JTG18/JTG04（RM=2，中国桥正解）字段组：
  "RM":2, "FT":1, "FPK":1860000,     // RM=2=JTG18/JTG04；FT=松弛系数(1.0)；FPK=预应力钢筋抗拉强度标准值
  "LR":true, "bOSRF":false,          // LR=低松弛；bOSRF=超张拉(false=不勾)
  "bRELAX":true,                     // 计松弛
  "US":1860000, "YS":1581000,        // 极限/屈服强度（随 UNIT，kN/m²）
  "FF":0.25, "WF":0.0015 }           // 曲率摩擦系数μ / wobble k(/长度)
  // —— 若用 CEB-FIP 2010（RM=9）则改用：{"RM":9,"RV":2.5,"TDMFK":1,"W_TYPE":0,...}（RV=ρ1000、TDMFK=Class）
```
**★松弛规范码 `RM` 对照**（RM=2 实测自 `GET /db/TDNT`，其余实测自包源 `_tendon.py`）：

| RM | 规范 | 专属字段 | 备注 |
|---|---|---|---|
| **2** | **JTG18/JTG04** | `FT`(松弛系数)、`FPK`(fpk)、`LR`(低松弛)、`bOSRF`(超张拉) | **★中国桥正解** |
| 9 | CEB-FIP 2010 | `RV`(ρ1000%)、`TDMFK`(Class 1慢/2中/3快) | |
| 8 / 1 | CEB-FIP 1990 / 1978 | `RV`(ρ1000%) | |
| 5 | European | `RV`(Class) | |
| 4 / 7 | IRC:18-2000 / 112-2011 | `RV`(factor) | |
| 0 | Magura / 无松弛 | `RV`(10/45) / — | `bRELAX` 区分 |

> **★规范一致性（你抽查到的问题，已实测解决）**：例桥原为 `RM=9`=CEB-FIP 2010，**对 JTG 桥应改 `RM=2`=JTG18/JTG04**——经 GUI 切换 + `GET /db/TDNT` 实测得：`RM:2, FT:1, FPK:1860000, LR:true, bOSRF:false, bRELAX:true`（不再用 `RV/TDMFK/W_TYPE`）。**`midas_civil` 包(v1.6.6) 的 `Relaxation` 助手不含 JTG18/JTG04（RM=2 会被当无松弛）——走 JTG 必须用原生 `PUT /db/TDNT` 直接给上述字段，不能用包助手。**

## 3. 钢束形状 `/db/TDNA` — 三种布置 + 线形
```jsonc
{ "NAME":"顶束-左主墩-01", "TDN_PROP":1, "TDN_GRUP":1,   // 引用特性/组
  "ELEM":[9,…,36],                       // 钢束经过的单元序列
  "INPUT":"2D",                          // 输入类型：2D(分 PROFY/PROFZ) / 3D(合一 PROF)
  "CURVE":"SPLINE",                      // 曲线类型：SPLINE(样条) / ROUND(圆弧，点用 RADIUS)
  "SHAPE":"ELEMENT",                     // ★布置坐标轴：ELEMENT(单元)/STRAIGHT(直线)/CURVE(曲线)
  // —— 2D 线形：PROFY 平面、PROFZ 竖向，每点 {PT:[沿程x, 偏移], bFIX, R} ——
  "PROFY":[{"PT":[0,0],"bFIX":false,"R":0},{"PT":[90,0],"bFIX":false,"R":0}],
  "PROFZ":[{"PT":[0,-0.32]},{"PT":[2.5,-0.12]},{"PT":[87.5,-0.12]},{"PT":[90,-0.32]}],
  // —— 按 SHAPE 取下列其一字段组 ——
  // SHAPE=ELEMENT(单元)：
  "INS_PT":"END-I", "INS_ELEM":9, "AXIS_IJ":"I-J", "XAR_ANGLE":0, "bPJ":true, "OFF_YZ":[3,0] }
  // SHAPE=STRAIGHT(直线)：  "IP":[x,y,z],"AXIS":"X|Y|VECTOR","VEC":[..],"XAR_ANGLE":,"bPJ":,"GR_AXIS":"X|Y","GR_ANGLE":
  // SHAPE=CURVE(曲线)：     "IP":[x,y,z],"RC":[圆心X,Y],"OFFSET":偏心,"DIR":"CW|CCW","XAR_ANGLE":,"bPJ":,"GR_AXIS":,"GR_ANGLE":
```
**三形状字段对照**（GUI「布置形状-坐标轴」）：

| SHAPE | GUI | 专属字段 | 适用 |
|---|---|---|---|
| `ELEMENT` | 单元 | `INS_PT`(端)/`INS_ELEM`/`AXIS_IJ`(I→J)/`OFF_YZ`[y,z] | 束沿梁单元局部坐标（**本桥用**）|
| `STRAIGHT` | 直线 | `IP`(插入点)/`AXIS`(假想x轴)/`VEC`/`GR_AXIS`·`GR_ANGLE`(绕轴旋转) | 直线梁全局坐标 |
| `CURVE` | 曲线 | `IP`/`RC`(曲梁圆心)/`OFFSET`(偏心)/`DIR`(顺/逆时针) | 弯梁 |

> **要点**：① 共有项 `XAR_ANGLE`(绕x轴旋转角)/`bPJ`(投影)。② `INPUT=2D` 用 `PROFY/PROFZ`；`3D` 用单个 `PROF`(点含 z)。③ `CURVE=ROUND` 时点用 `RADIUS` 字段、`SPLINE` 用 `R`+`bFIX`。④ `PROFZ` 的 z 与截面 `OFFSET_PT="CT"`(节点在顶)一致：**z 负=顶以下**（`z_from_top=−PROFZ_z`）。⑤ 标准钢束 `bTP=true`+`CNT` 可批量复制。

## 4. 张拉力 `/db/TDPL`
```jsonc
{ "ITEMS":[ {"ID":1, "LCNAME":"预应力", "GROUP_NAME":"预应力#12", "TENDON_NAME":"顶束-左主墩-01",
            "TYPE":"STRESS", "ORDER":"BEGIN", "BEGIN":1395000, "END":1395000, "GROUTING":1} ] }
```
> `TYPE` 应力(STRESS)/力(FORCE)；`ORDER` 张拉端 BEGIN/END/BOTH；`BEGIN/END`=张拉端应力 σcon；`GROUP_NAME`=预应力#N 决定哪个施工阶段激活；`GROUTING`=灌浆阶段。

## 5. 映射与反算（三层取值）
- **① JTG 确定值**（回规范）：σcon=0.75fpk=1395 MPa、摩擦 μ/wobble k（表 6.2.2）、锚具回缩（表 6.2.3）、**松弛规范=JTG18/JTG04**、Aps/fpd/fpk。
- **② 结构惯例**（无大样图→权威调研，禁照搬参照模型数值）：股数/管径、每节段束数、线形族（顶板束悬臂近顶、底板合龙束近底）。
- **③ demand**（回 MIDAS，不手算）：弯矩包络 + 截面特性 → 反算束数（**SLS 消压 §6.3.1 + ULS 抗弯 §5.2.2** 双控取大）。
