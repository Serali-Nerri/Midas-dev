# 施工阶段荷载（建模模块）

> **流程（静力荷载第一步）**：先搭两套容器——**静力工况**(`/db/stld`，本步只建 **自重 / 预应力 / 施工阶段荷载** 三个) + **荷载组**(`/db/LDGR`，**一次建齐 49 个**，是荷载的顶层目录树) → 再把各荷载**挂到「工况(LCNAME)＋荷载组(GROUP_NAME)」**：自重(`/db/BODF`) → 隔板(`/db/CNLD`，挂自重) → 挂篮/混凝土湿重/吊架/压重(`/db/CNLD`，挂施工阶段荷载)。
> **★工况 vs 荷载组（两个正交维度，都要挂）**：**工况**=力学类别（决定参与哪种分析/组合）；**荷载组**=施工阶段的激活/钝化单位。每条荷载同时写 `LCNAME` 与 `GROUP_NAME`。
> **★本步只建 3 个工况**：二期恒载、系统升/降温、梯度升/降温**工况留到下一步**（「二期与温度荷载」）；但 **49 个荷载组本步一次建齐**（含二期恒载组、预应力#0–12 等占位组）。
> **★硬依赖**：工况、荷载组**先建**（荷载按名引用）；本步在「边界」之后、「二期与温度荷载」之前。预应力**真值在「钢束」模块**建（本步只占位预应力工况+组）。

## 1. API 接口
| 荷载 | 端点 | 说明 |
|---|---|---|
| 静力工况 | `/db/stld`（小写）| 本步建 自重/预应力/施工阶段荷载（`TYPE=CS`）|
| 荷载组 | `/db/LDGR` | 一次建齐 49 组（命名容器）|
| 自重 | `/db/BODF` | body force 重力系数 |
| 节点集中力 | `/db/CNLD` | 隔板/挂篮/湿重/吊架/压重（`ITEMS` 风格）|

## 2. JSON 各字段含义
```jsonc
// 工况 /db/stld：{"1":{"NO":1,"NAME":"自重","TYPE":"CS","DESC":""}}   // CS=施工阶段类
// 荷载组 /db/LDGR：{"1":{"NAME":"挂篮0"}}                              // 仅命名容器
// 自重 /db/BODF：{"1":{"LCNAME":"自重","GROUP_NAME":"自重","FV":[0,0,-1.04]}}
//   FV=[X,Y,Z] 重力系数；Z = −(规范计重容重 / 模型材料密度)：材料25+规范26→−1.04；密度已设规范值则 −1.0
// 节点集中力 /db/CNLD：
{ "<节点>": { "ITEMS": [
   { "ID":1, "LCNAME":"自重", "GROUP_NAME":"0#隔板",
     "FX":0,"FY":0,"FZ":-1659.45, "MX":0,"MY":0,"MZ":0 } ] } }   // 同节点多荷载=多 ITEMS；湿重带偏心 MY
```
> **要点**：① 力/弯矩带单位——本模块例子 kN-m（`FZ` kN、`MY` kN·m）；N-mm 模型则为 N / N·mm（×1000）——录入/回读前先 `GET /db/UNIT`（核心准则 2）。② 自重系数 `−1.04` 非常量，取决于材料密度，建模前查材料。③ `CNLD` 同节点多荷载 = 多 `ITEMS`。

## 3. 映射与格式
- **工况(3)**：自重 / 预应力 / 施工阶段荷载（均 `TYPE=CS`）。
- **荷载组(49)**：挂篮0–12、混凝土湿重1–12、0#隔板/端隔板/跨中隔板、边跨/中跨吊架、边跨/中跨压重、自重、二期恒载、预应力#0–12＋边跨/中跨预应力。决策文档「荷载」章给全表。
- **挂靠规则**：自重 BODF→(自重,自重)；5 隔板 CNLD→(自重, 各自隔板组)；挂篮/湿重/吊架/压重 CNLD→(施工阶段荷载, 各自组)。
- **隔板 FZ 量值算法**：`FZ = −箱室空腔面积 × 隔板厚 t × 26`（PSC 重度 26 kN/m³ 回 `code_tables.md`「材料—重度」，JTG D60-2015 表4.2.1；隔板系后加节点荷载，与自重系数 −1.04 各管各、不重复计）。**空腔面积由模型 NCE2 截面参数计算**（与受力分析同源，不读图、不写死）：`void = (SWIDTH − 2·BO1 − 2·BI1)·(H − HI1 − HI6) − BI2·HI2 − BI5·HI5`（净宽×净高 − 上下梗腋，对称截面；参数位映射见「截面库/单箱多室2-NCE2」）。**厚度 t**：用户给定则用之；未给定按「施工方法/悬臂浇筑施工」§6 经验初拟表取值并提交用户审核。过人洞默认按实心不扣（偏安全），除非用户指定扣孔。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（数据由 `GET /db/*` API 实测；例子 kN-m——核心准则 2）。

**① 工况 `/db/stld`（仅 3 个）+ 荷载组 `/db/LDGR`（49 个）**
```json
{"Assign":{"1":{"NO":1,"NAME":"自重","TYPE":"CS","DESC":""},
  "2":{"NO":2,"NAME":"预应力","TYPE":"CS","DESC":""},
  "3":{"NO":3,"NAME":"施工阶段荷载","TYPE":"CS","DESC":""}}}
```
```python
groups = (["挂篮%d"%i for i in range(13)] + ["混凝土湿重%d"%i for i in range(1,13)] +
          ["0#隔板","端隔板","跨中隔板","边跨吊架","中跨吊架","中跨压重","边跨压重","自重","二期恒载"] +
          ["预应力#%d"%i for i in range(13)] + ["边跨预应力","中跨预应力"])     # 49 组（含二期/预应力占位）
MidasAPI("PUT","/db/LDGR",{"Assign":{i+1:{"NAME":g} for i,g in enumerate(groups)}})
```

**② 自重 `/db/BODF` + 隔板 `/db/CNLD`（均挂工况「自重」）**
```json
{"Assign":{"1":{"LCNAME":"自重","GROUP_NAME":"自重","FV":[0,0,-1.04]}}}
```
```json
{"Assign":{
  "2": {"ITEMS":[{"ID":1,"LCNAME":"自重","GROUP_NAME":"端隔板", "FX":0,"FY":0,"FZ":-304.98, "MX":0,"MY":0,"MZ":0}]},
  "23":{"ITEMS":[{"ID":1,"LCNAME":"自重","GROUP_NAME":"0#隔板", "FX":0,"FY":0,"FZ":-1659.45,"MX":0,"MY":0,"MZ":0}]},
  "39":{"ITEMS":[{"ID":1,"LCNAME":"自重","GROUP_NAME":"跨中隔板","FX":0,"FY":0,"FZ":-147.03, "MX":0,"MY":0,"MZ":0}]},
  "55":{"ITEMS":[{"ID":1,"LCNAME":"自重","GROUP_NAME":"0#隔板", "FX":0,"FY":0,"FZ":-1659.45,"MX":0,"MY":0,"MZ":0}]},
  "76":{"ITEMS":[{"ID":1,"LCNAME":"自重","GROUP_NAME":"端隔板", "FX":0,"FY":0,"FZ":-304.98, "MX":0,"MY":0,"MZ":0}]}}}
```
> **例桥隔板 FZ 推导**（§3 算法，kN-m；空腔面积由对应母截面 vSIZE 按公式算得，厚度经用户审核）：0#隔板 = 25.530 m²(1-1 支座截面)×2.5 m×26 = **1659.45**；端隔板 = 9.775 m²(3-3 边墩截面)×1.2 m×26 = **304.98**；跨中隔板 = 11.310 m²(2-2 跨中截面)×0.5 m×26 = **147.03**——与上方 JSON 的 FZ 逐值吻合。

**③ 施工荷载 `/db/CNLD`（工况「施工阶段荷载」；挂篮纯 FZ、湿重带偏心 MY）**
```json
{"Assign":{
  "20":{"ITEMS":[{"ID":1,"LCNAME":"施工阶段荷载","GROUP_NAME":"挂篮0",   "FX":0,"FY":0,"FZ":-1113.29,"MX":0,"MY":0,      "MZ":0},
                 {"ID":2,"LCNAME":"施工阶段荷载","GROUP_NAME":"混凝土湿重1","FX":0,"FY":0,"FZ":-2226.58,"MX":0,"MY":-3896.51,"MZ":0}]},
  "26":{"ITEMS":[{"ID":1,"LCNAME":"施工阶段荷载","GROUP_NAME":"混凝土湿重1","FX":0,"FY":0,"FZ":-2226.58,"MX":0,"MY":3896.51, "MZ":0}]}}}
```
> 湿重 `MY` = 下一节段湿混凝土悬挑产生的偏心弯矩；**左悬臂 −MY、右悬臂 +MY（对称）**。挂篮恒 −1113.29 kN（纯 FZ）。吊架 −556.64、边跨压重 −329.94、中跨压重 −403.45 kN（均纯 FZ）。

**④ 核对（API 实测 GET，kN-m）**：`GET /db/stld`=本步 3 工况 ✓；`GET /db/LDGR`=49 组 ✓；`GET /db/BODF` `FV=[0,0,-1.04]` ✓；`GET /db/CNLD` 隔板 0#=−1659.45 / 端=−304.98 / 跨中=−147.03、挂篮=−1113.29、湿重 FZ=−2226.58 **MY=∓3896.51** ✓。
