# 验算（建模模块 · S13 待验算层）

> **定位**：与前面"确定层"不同，这是**引擎驱动的迭代层**——拉 MIDAS 内力/应力 → 按 JTG 校核 → 诊断超限 → 用四杠杆补强 → 录回 MIDAS → 重分析，循环至主控全过。
> **★为什么要自建引擎**：MIDAS Civil NX **无中国 PSC 设计码**（设计→PSC 仅 KSCE/AASHTO/EC/BS/IRC），只出内力/应力、不出"是否满足 JTG"。
> **解法**：① 自建 Python **JTG 引擎**——拉 MIDAS 内力/应力，按 JTG3362-2018 校核、算超限量、反算补强；② 外部 **CDN 工具**（基于 JTG3362）导主控验算表作**最终判据**。
> **★分工**：**CDN 主控表转绿 = 终极目标；自建引擎 = 诊断器**（指导改模型，不替代 CDN 出最终结论）。σ 约定：拉 +、压 −（与 MIDAS 一致）。限值数值回 `code_tables.md`、规范条文回 `code/`。

## 1. 主控验算集合（工程实践选 4 项，非全表都要过）
| 验算项 | 作用组合 | 判据 | JTG 条文 |
|---|---|---|---|
| 正截面**抗弯** γ0Md≤Mu | 承载能力·基本 | Mu(钢束+普通钢筋) | §5.2.2 |
| 斜截面**抗剪** γ0Vd≤Vu | 承载能力·基本 | 腹板抗压上限 + 箍筋 Vcs | §5.2.9 |
| 正截面**抗裂(消压)** | 频遇组合 | σst−0.80σpc≤0（分段浇筑）| §6.3.1 |
| 腹板斜截面**抗裂(主拉)** σtp | 频遇组合 | ≤0.40ftk（全预应力现浇）| §6.3.3 |

> 二档保持（多已自动满足）：持久状态压应力 §7.1.5 / 主压 §7.1.6（标准组合）、预应力筋应力 §7.1.5、施工应力 §7.2.8、最小配筋率 §9.1.12/9.1.13（按 Mud/Mcr≥1 的安全系数判，**非几何 ρ 地板**）。

## 2. 数据通路（每检查抽哪个表，`POST /post/TABLE`）
| MIDAS 表 | 给什么 | 用于 |
|---|---|---|
| `SECTIONALL` | A/Asz/Iyy/Czp/Czm/周长（权威截面特性）| h、W=I/c；**变高梁高用解析 H(x)，勿用 section-id 高度** |
| `BEAMFORCE` | 组合 Axial/Shear-z/Moment-y | 抗弯/抗剪 demand |
| `BEAMSTRESSPSC` | 纤维应力 + 分量(恒/钢束/徐变/收缩) + Sig-Ps | 消压 σpc、施工应力、**主拉 σtp** |
| `BEAMSTRESS` | 组合四角净纤维应力 | σkc、消压 σ_net |
| `/db/RPSC` | 截面钢筋（纵筋 MBARS + 箍筋 SBAR）| 录配筋供 CDN/Mu/Vu 读 |

> **★力类 vs 应力类（实测规律）**：抗弯/抗剪是**力类**——demand 取基本组合 My/Vz×γ0、capacity 按 JTG 算，可逐元干净标定 CDN。抗裂消压/主拉是**应力类**——σ **读 MIDAS 原生截面应力**（莫尔圆自算会失败）；主拉 σtp 取 `BEAMSTRESSPSC` 的 `Sig-Ps(Max)`、**只取腹板点 Pos-5..Pos-10**（Pos-3/4 是底翼缘弯曲点会污染），频遇包络。
> ⚠ **`BEAMSTRESSPSC` 必须逐单元拉**（`KEYS:[单元]`）：批量取（多单元×全工况×多截面点）会拖垮服务端致 wedge。

## 3. 四补强杠杆（互不重叠，全部须真正建入 MIDAS，CDN 方予采信）
| 杠杆 | 治什么 | 反算 | 录入端点 |
|---|---|---|---|
| **底束**（纵向预应力）| 抗弯 sagging + 正截面抗裂 | 束数反算（SLS 消压 + ULS 抗弯）| `/db/TDNT·TDNA·TDPL`（钢束模块）|
| **普通钢筋** As(x) | 最小配筋 + 抗弯/抗裂兜底 | 反算底/顶筋面积 | `/db/RPSC` 纵筋 `MBARS` |
| **抗剪箍筋** | 抗剪 + 抗扭 | 反算 ρsv→Φ/间距/肢数 | `/db/RPSC` 箍筋 `SBAR` `OPT_SR` |
| **竖向预应力** | 腹板主拉 §6.3.3 | 反算 σcy | `/db/RPSC` `SBAR` `OPT_SBW` |

> **★分工铁律**：钢束影响弹性内力（必须建进 MIDAS）；钢筋/箍筋**不影响弹性内力，但影响验算**（Mu 含 As、Vu 含箍筋）→ **必须按截面录进 `/db/RPSC`，否则 CDN 一直红**。"钢筋不必建进 MIDAS"只对求内力成立、对 CDN 通过不成立。

## 4. RPSC 录配筋（API 接口 + 易错点）
| 项 | 内容 |
|---|---|
| 端点 | `/db/RPSC`（截面管理器-钢筋；**按截面 id**，可 GET/PUT）+ `/db/MATD`（钢筋材料）|
| 结构 | 纵筋 `MBARS`（每端一组，内含多条 `MBAR_ITEMS`）+ 箍筋 `SBAR_ITEMS` |
```jsonc
// 纵筋一条：{"IJ":"I","NAME":"d16","REF_Z":1,"Z":<保护层>,"NUM":<根数>,"SPACING":<间距>,"REF_Y":0,"Y":0,"PART":0}
//   ★REF_Z=1=底纤维起算、REF_Z=0=顶纤维起算
// 箍筋一条：{"OPT_SR":true,"SR_PITCH":<间距>,"SR_AW":<单肢面积Asv>,  // 抗剪箍筋
//           "OPT_TR":false,   // 抗扭(对抗剪零影响)
//           "OPT_SBW":false,  // 腹板竖筋=竖向预应力(主拉 §6.3.3)
//           "OPT_DR":false}   // 弯起筋
```
> **易错点**：① **`REF_Z=1`底 / `REF_Z=0`顶**——sagging 底受拉 As_bot→`REF_Z=1`；hogging 顶受拉→`REF_Z=0`。**放反 = 钢筋被当压钢、抗弯近零贡献**。② 先 `PUT /db/MATD` 给混凝土加 `REBAR_CODENAME`(对齐混凝土码) + HRB400，否则 `d##` 名不解析。③ virgin 截面首 PUT 必带 `SBAR_ITEMS` 块（全关也要），缺则报 `Wrong Field`。④ taper 段 `OPT_MBAR_J=true` + 显式 I/J 双组同值。⑤ **RPSC 在当前模型单位**（核心准则 2，录入/回读前 `GET /db/UNIT`）。

## 5. 超限补强反算
| 超限项 | 补强（优先级）| 反算 |
|---|---|---|
| 主拉 σtp | **竖向预应力**（首选）| `σcy=(T²−τ²−T·σcx)/(T−σcx)`，T=0.4ftk；σcy=Apv·σpe/(t_web·sv) 回代验证 |
| 正截面消压 | **调钢束/底束** | `Δσpc=margin/0.80`；ΔP=Δσpc/(1/A+e·c/I)；ΔAp=ΔP/σpe |
| 抗剪压坏 | **腹板加厚**（唯一）| b≥γ0Vd/(0.51e-3·√fcu·h0)；竖向预应力/箍筋无效 |
| 抗剪（非压坏）| **箍筋** | 由 Vcs 式反解 ρsv→Φ/肢数/间距 |
| 抗弯 | **底束/普通钢筋** | γ0Md 与 Mu 比，不足才补 |

> ★ **加预应力前先认清受拉纤维 + 锚固偏心**：误加底束修边跨消压会更糟（底束锚桥台、下偏心→锚下局部 hogging→顶纤维更拉）。**方向错=负优化**。
> ★ **纵向束治弯曲消压，主拉 σtp 归竖向预应力**（堆纵向底束治 σtp 无效、还会先压爆持久压）。

## 6. 例子 + 迭代回路
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m。`/db/RPSC` 实测：7 母截面均已录纵筋 + 箍筋槽——支座(§1) `d16`、跨中(§2) `d20`、边墩(§3) `d12`（顶/底两组，`OPT_MBAR_J=true` 双端）；箍筋 `OPT_SR=true`（`SR_PITCH/SR_AW`），竖向预应力槽 `OPT_SBW` 待主拉超限时启用。
```jsonc
// GET /db/RPSC 截面2(跨中) 实测结构（节选）
{"OPT_MBAR_J":true,"OPT_SBAR_J":false,
 "SBAR_ITEMS":[{"OPT_SR":true,"SR_PITCH":…,"SR_AW":…,"OPT_SBW":false,"OPT_TR":false,"OPT_DR":false}],
 "MBARS":[{"MBAR_ITEMS":[{"IJ":"I","NAME":"d20","REF_Z":1,"NUM":360,…},{"IJ":"I","NAME":"d20","REF_Z":0,…}]},
          {"MBAR_ITEMS":[{"IJ":"J",…同值…}]}]}
```
**三步迭代回路（务必）**：① 锁主控集合（4 项）→ ② 逐项标定 CDN（证 Python 引擎=CDN 一致）→ ③ 引擎驱动调整、零手导迭代。
- **改完模型必 `POST /doc/ANAL` 重分析**，CDN 才读到新态（仅 PUT+save 不重分析 → CDN 导出与改前一致）。
- 改材料/几何/MSIZE/钢束 → 必重算；仅改组合/录配筋（不改弹性内力）→ 后处理为主，但录配筋后仍重分析让 CDN 刷新。
- 改模型前备份 `.mcb` 或留可复现脚本。
