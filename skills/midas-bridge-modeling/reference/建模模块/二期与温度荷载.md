# 二期与温度荷载（建模模块）

> **流程（静力荷载第二步）**：在「施工阶段荷载」之后，补建剩余静力工况并挂载——**二期恒载**(工况+`/db/bmld` 均布) + **温度**(系统升/降温 `/db/stmp`、梯度升/降温 `/db/btmp`)。
> **★工况本步建、荷载组沿用**：本步新增 5 个工况（二期恒载、系统升温、系统降温、梯度升温、梯度降温）；荷载组在上一步已建齐 49 个（二期恒载组在内），本步不再新建组。
> **★温度挂"默认荷载组"**（`GROUP_NAME=""`）：升降温/梯度温**全施工阶段都产生**，不绑某个施工组；二期恒载则挂「二期恒载」组（成桥后一次施加）。
> **★硬依赖**：在「施工阶段荷载」之后、「移动荷载」之前；二期 `bmld` 作用于全主梁单元（须单元已建）。

## 1. API 接口
| 荷载 | 端点 | 说明 |
|---|---|---|
| 静力工况 | `/db/stld` | 本步建 二期恒载(`CS`) + 系统升/降温(`T`) + 梯度升/降温(`TPG`) |
| 梁单元荷载 | `/db/bmld` | 二期恒载均布（`ITEMS`，键=单元号）|
| 系统温度 | `/db/stmp` | 整体均匀温变（工况 `TYPE=T`）|
| 梁截面温度梯度 | `/db/btmp` | 竖向折线梯度（工况 `TYPE=TPG`）|

## 2. JSON 各字段含义
```jsonc
// 工况 /db/stld：二期=CS、系统温=T、梯度温=TPG
{ "4":{"NO":4,"NAME":"二期恒载","TYPE":"CS"}, "5":{"NO":5,"NAME":"系统升温","TYPE":"T"},
  "7":{"NO":7,"NAME":"梯度升温","TYPE":"TPG"} }
// 梁单元荷载 /db/bmld（二期均布）：
{ "<单元>": { "ITEMS": [
   { "ID":1,"LCNAME":"二期恒载","GROUP_NAME":"二期恒载","CMD":"BEAM","TYPE":"UNILOAD",
     "DIRECTION":"GZ","USE_PROJECTION":false,"USE_ECCEN":false,
     "D":[0,1,0,0], "P":[-48.72,-48.72,0,0] } ] } }            // D=相对位置(0→1), P=两端集度
// 系统温度 /db/stmp：{"1":{"TEMPER":25,"LCNAME":"系统升温","GROUP_NAME":""}}   // 升+25/降−20
// 梁截面梯度 /db/btmp：
{ "1": { "ITEMS": [ { "ID":1,"LCNAME":"梯度升温","GROUP_NAME":"","DIR":"LZ","REF":"Top","NUM":2,"bPSC":false,
   "vSECTTMP":[ {"TYPE":"ELEMENT","VAL_B":16,"VAL_H1":0,  "VAL_H2":0.1,"VAL_T1":20, "VAL_T2":6.7},
                {"TYPE":"ELEMENT","VAL_B":16,"VAL_H1":0.1,"VAL_H2":0.4,"VAL_T1":6.7,"VAL_T2":0} ] } ] } }
```
> **要点**：① `bmld` 的 `P` 单位 kN/m（与 N/mm 同数值，无歧义）。② 温度 `TEMPER`/梯度 `VAL_T*` 单位 ℃；`VAL_B`/`VAL_H*` 随 `/db/UNIT`（本例 m）。③ 温度 `GROUP_NAME=""`=默认组（全阶段产生）。④ 二期与温度的取值均按 JTG（回决策文档/规范——核心准则 1）。

## 3. 映射与格式
- **工况(5)**：二期恒载（`CS`）+ 系统升温/降温（`T`）+ 梯度升温/降温（`TPG`）。
- **二期恒载**：`bmld` 全主梁单元 `UNILOAD GZ`，集度按 JTG 算（铺装+人行道+栏杆，回决策文档「二期恒载」），挂(二期恒载,二期恒载)。
- **温度**：系统 `stmp` 升/降温、梯度 `btmp` 升/降温，均挂对应温度工况 + **默认组 `""`**。温度值/梯度折线按 JTG D60。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m，桥面全宽 16 m（数据由 `GET /db/*` API 实测；例子 kN-m——核心准则 2）。

**① 工况 `/db/stld`（接上一步 NO 续 4–8）**
```json
{"Assign":{"4":{"NO":4,"NAME":"二期恒载","TYPE":"CS","DESC":""},
  "5":{"NO":5,"NAME":"系统升温","TYPE":"T","DESC":""},"6":{"NO":6,"NAME":"系统降温","TYPE":"T","DESC":""},
  "7":{"NO":7,"NAME":"梯度升温","TYPE":"TPG","DESC":""},"8":{"NO":8,"NAME":"梯度降温","TYPE":"TPG","DESC":""}}}
```

**② 二期恒载 `/db/bmld`（全 76 单元均布；P=−48.72 kN/m）**
```python
bmld = {e:{"ITEMS":[{"ID":1,"LCNAME":"二期恒载","GROUP_NAME":"二期恒载","CMD":"BEAM","TYPE":"UNILOAD",
        "DIRECTION":"GZ","USE_PROJECTION":False,"USE_ECCEN":False,"D":[0,1,0,0],"P":[-48.72,-48.72,0,0]}]}
        for e in range(1,77)}
MidasAPI("PUT","/db/bmld",{"Assign":bmld})
```
> 二期 48.72 kN/m = 铺装 + 人行道 + 栏杆，按 JTG 算（值回决策文档「二期恒载」）。

**③ 温度：系统 `/db/stmp` + 梯度 `/db/btmp`（均挂默认荷载组 `""`）**
```json
{"Assign":{"1":{"TEMPER":25,"LCNAME":"系统升温","GROUP_NAME":""}}}
{"Assign":{"1":{"TEMPER":-20,"LCNAME":"系统降温","GROUP_NAME":""}}}
```
```json
{"Assign":{"1":{"ITEMS":[{"ID":1,"LCNAME":"梯度升温","GROUP_NAME":"","DIR":"LZ","REF":"Top","NUM":2,"bPSC":false,
  "vSECTTMP":[{"TYPE":"ELEMENT","VAL_B":16,"VAL_H1":0,"VAL_H2":0.1,"VAL_T1":20,"VAL_T2":6.7},
              {"TYPE":"ELEMENT","VAL_B":16,"VAL_H1":0.1,"VAL_H2":0.4,"VAL_T1":6.7,"VAL_T2":0}]}]}}}
```
> 系统温度 +25 / −20 ℃。梯度升温竖向折线：顶面 20℃ → 0.1 m 处 6.7℃ → 0.4 m 处 0（`DIR=LZ` 竖向、`REF=Top` 自顶起、`VAL_B`=顶板宽）；梯度降温为其反向。温度值按 JTG D60。

**④ 核对（API 实测 GET，kN-m）**：`GET /db/stld` 共 8 工况（含本步 5 个）✓；`GET /db/bmld`=76 单元 P=−48.72 ✓；`GET /db/stmp`=升/降温 +25/−20 ✓；`GET /db/btmp`=76 梯度（顶 20→6.7→0）✓。
> GET 回读附带默认字段（PUT 可省）：`bmld` 多 `USE_ADDITIONAL/ADDITIONAL_I_END/…`；`btmp` 的 `vSECTTMP` 元素多 `ELAST/THERMAL`(=0)。
