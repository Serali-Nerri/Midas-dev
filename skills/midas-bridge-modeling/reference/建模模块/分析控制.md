# 分析控制（建模模块）

> **流程**：设三张**分析控制表**，模型才能正确分析与后处理——
> ① **施工阶段分析控制**(`/db/STCT`)：计时变/徐变、徐变迭代、自动时间步；
> ② **特征值分析控制**(`/db/eigv` + `/db/STYP` 自重转质量)：求自振频率；
> ③ **移动荷载分析控制**(`/db/mvctch`)：输出项 + **汽车冲击系数**（按基频）。
> **★三表缺一不可（子代理曾崩在此）**：曾出现"计算有效分布系数算不出来 / 施工阶段后处理崩溃（forrtl severe）"——根因是**分析控制表不全（须≥3 表）+ 有效宽度未算**。建模收尾务必把这三表都设上。
> **★有效宽度先算**：构造阶段分析前，PSC 有效宽度须已生成（GUI 主路径，见「移动荷载」模块）——否则有效分布系数缺失、分析报错。
> **★冲击系数依赖链**：`STYP`(自重转质量) → `eigv`(特征值) → `POST /doc/ANAL` 取**基频 f** → 写入 `mvctch.FREQ.USER_F` → MIDAS 按 JTG D60 §4.3.2 定 μ。

## 1. API 接口
| 表 | 端点 | 作用 |
|---|---|---|
| 施工阶段分析控制 | `/db/STCT` | 时变/徐变、迭代、自动时间步、最终阶段 |
| 自重转质量 | `/db/STYP` | 特征值分析把自重计入质量 |
| 特征值分析控制 | `/db/eigv` | 振型数/求解法/收敛 |
| 移动荷载分析控制 | `/db/mvctch` | 输出项 + 冲击系数（基频） |

## 2. JSON 各字段含义
```jsonc
// ① 施工阶段分析控制 /db/STCT：
{ "bINC_TDE":true,         // ★计入时间依存效应(徐变/收缩/弹模发展)——施工阶段必须 true
  "bTTLE_CS":true, "bTTLE_ES":true,   // 计 收缩 / 弹模随龄期
  "iITER_CR":5, "TOL_CR":0.01,        // 徐变迭代次数 / 容差
  "bATS":true, "iT10":2,"iT100":5,"iT1K":7,"iT5K":10,"iT10K":20,  // 自动时间步细分(按持续天数档)
  "bVAR":true,              // 变截面
  "bLAST_FINAL":true, "TYPE":"BOTH", "iNLA_TYPE":1 }   // 末阶段=最后；BOTH=施工+成桥
// ② 自重转质量 /db/STYP：
{ "MASS":1, "GRAV":9.806, "bSELFWEIGHT":true, "bMASSOFFSET":true, "SMASS":1 }  // 自重按 g=9.806 转质量
// ③ 特征值分析控制 /db/eigv：
{ "TYPE":"LANCZOS", "iFREQ":10, "iITER":20, "TOL":1e-10 }   // Lanczos 法，求前 10 阶振型
// ④ 移动荷载分析控制 /db/mvctch（★须给全字段，缺"计算方法字段/成对分组开关"→报 "Wrong Field" 拒写）：
{ "POINT":"INF",                        // 影响线/面结果位置
  "iIGP":0,                             // 影响线生成点选项
  "UNUMT":3,                            // ★每单元影响线分点数(决策文档"每单元3点")
  "PLATE":"NODAL",                      // ★板单元影响面法=节点法(NODAL)
  "bSTRCALC":true,                      // 计算应力
  "FRAME":"AXIAL",                      // ★框架内力计算法
  "bCSTRCALC":true,                     // 计算合成应力
  "bREAC":true,  "bRG":false, "RGN":"", // 反力输出 + (仅特定组开关/组名)
  "bDISP":true,  "bDG":false, "DGN":"", // 位移输出 + (仅特定组)
  "bFM":true,    "bFG":false, "FGN":"", // 内力输出 + (仅特定组)
  "bL":true,     "bLG":false, "LGN":"", // 车道输出 + (仅特定组)
  "bIF":true,                           // ★计冲击系数
  "iCODETYPE":0, "iNFM":0, "bBC":true, "iBC":0,   // 规范类型/内力法/边界反力选项
  "FREQ":{"USER_F":0.898464} }          // ★结构基频(Hz)——由特征值分析取得后填入，驱动 μ
```
> **★"Wrong Field" 教训**：`mvctch` 不能只给输出开关(`bSTRCALC/bREAC/…`)+`bIF`+`FREQ`——**必须连方法字段(`iIGP/UNUMT/PLATE/FRAME`)与每个输出的成对分组开关(`bRG/RGN`、`bDG/DGN`、`bFG/FGN`、`bLG/LGN`)及 `iNFM/bBC/iBC` 一并给全**，否则 MIDAS 读到未初始化字段、报 "Wrong Field" 而**整表不写入**（GET 回空）。字段值实测自成品模型 `GET /db/mvctch`。
> **要点**：① `STCT.bINC_TDE=true` 是施工阶段计徐变的总开关；徐变迭代 `iITER_CR/TOL_CR` 与自动时间步 `iT*` 用 MIDAS 规范默认即可。② 特征值用 `STYP` 把**自重转为质量**（否则无质量、求不出频率）。③ `mvctch.FREQ.USER_F` 是**用户输入基频**法：先跑特征值得 f，再回填这里。

## 3. 映射与格式
- **三表取值**：均为 MIDAS 规范默认/工程惯例——`STCT`（计徐变 `bINC_TDE=true`、迭代 5/0.01、自动时间步默认档、末阶段=最后）、`eigv`（Lanczos、10 阶）、`STYP`（自重转质量 g=9.806）、`mvctch`（开启各输出 + `bIF=true`）。
- **冲击系数 μ**：确定量回规范（核心准则 1）——JTG D60-2015 §4.3.2：`f<1.5 Hz → μ=0.05`；`1.5≤f≤14 → μ=0.1767·ln(f)−0.0157`；`f>14 → μ=0.45`。f 由特征值分析得，填入 `mvctch.FREQ.USER_F`，MIDAS 内部算 μ。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（数据由 `GET /db/*` API 实测）。

**① 施工阶段分析控制 `/db/STCT`**
```json
{"Assign": {"1": {"bLAST_FINAL":true,"TYPE":"BOTH","bINC_TDE":true,"bTTLE_CS":true,"bTTLE_ES":true,
  "bVAR":true,"iITER_CR":5,"TOL_CR":0.01,"bCNS":true,"iNLA_TYPE":1,
  "bATS":true,"iT10":2,"iT100":5,"iT1K":7,"iT5K":10,"iT10K":20,"bCALC_CSP":true}}}
```

**② 自重转质量 `/db/STYP` + 特征值分析控制 `/db/eigv`**
```json
{"Assign": {"1": {"MASS":1,"GRAV":9.806,"bSELFWEIGHT":true,"bMASSOFFSET":true,"SMASS":1}}}
{"Assign": {"1": {"TYPE":"LANCZOS","iFREQ":10,"iITER":20,"iDIM":1,"TOL":1e-10}}}
```

**③ 跑分析取基频 → 移动荷载分析控制 `/db/mvctch`（含冲击系数）**
```python
MidasAPI("POST", "/doc/ANAL", {})                       # 跑施工阶段 + 特征值分析
tb = MidasAPI("POST", "/post/TABLE", {"Argument":{"TABLE_NAME":"EIG","TABLE_TYPE":"EIGENVALUEMODE"}})
# 频率在 SUB_TABLES["EIGENVALUE ANALYSIS"]：列=[ModeNo, Freq(rad/sec), Freq(cycle/sec), Period, Tol]
for st in tb["EIG"]["SUB_TABLES"]:
    if "EIGENVALUE ANALYSIS" in st:
        f1 = float(st["EIGENVALUE ANALYSIS"]["DATA"][0][2])   # 第1阶 cycle/sec(Hz)，本桥实测≈0.8985
# ★方法字段+成对分组开关+iNFM/bBC/iBC 必须给全，否则 "Wrong Field"（详见 §2）
MidasAPI("PUT", "/db/mvctch", {"Assign": {"1": {
  "POINT":"INF","iIGP":0,"UNUMT":3,"PLATE":"NODAL","bSTRCALC":True,"FRAME":"AXIAL",
  "bCSTRCALC":True,"bREAC":True,"bRG":False,"RGN":"","bDISP":True,"bDG":False,"DGN":"",
  "bFM":True,"bFG":False,"FGN":"","bL":True,"bLG":False,"LGN":"","bIF":True,
  "iCODETYPE":0,"iNFM":0,"bBC":True,"iBC":0,"FREQ":{"USER_F":f1}}}})
```
> 本桥基频 f≈0.898 Hz < 1.5 → **μ=0.05**（JTG D60-2015 §4.3.2）。冲击系数随后自动施加于汽车移动荷载。
> 第1阶为竖弯振型（方向因子 TRAN-Z≈93%），正是竖向冲击相关的基本频率——取 `SUB_TABLES["EIGENVALUE ANALYSIS"].DATA[0]` 第3列(cycle/sec)。

**④ 核对（API 实测 GET）**：`GET /db/STCT` `bINC_TDE=true`、`iITER_CR/TOL_CR=5/0.01`、自动时间步 `iT10..iT10K=2/5/7/10/20` ✓；`GET /db/eigv` `LANCZOS, iFREQ=10` ✓；`GET /db/STYP` `MASS=1,GRAV=9.806,bSELFWEIGHT=true` ✓；`GET /db/mvctch` `bIF=true, FREQ.USER_F=0.898464` ✓。
> **★分析收尾自检（防子代理式崩溃）**：① STCT/eigv/mvctch **三表齐全**；② PSC **有效宽度已 GUI 生成**（见「移动荷载」）；③ 改模型后必 `POST /doc/ANAL` 重分析。三者缺一即可能"有效分布系数算不出 / 后处理崩溃"。
