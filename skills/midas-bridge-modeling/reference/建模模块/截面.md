# 截面（建模模块）

> **流程**：建**设计截面（PSC，控制截面，单一几何）** + **变截面（TAPERED，嵌两端设计截面几何）**，端点都是 `/db/SECT`。每个截面的 vSIZE 数组**位↔尺寸映射查 `截面库/` 对应类型文件**（例桥单箱单室箱梁→`单箱多室2-NCE2.md`）；本模块只讲"PSC/TAPERED 怎么 PUT"。
> **★硬依赖**：变截面**必在单元之前**建（单元创建即按 SECT 指派截面）；变截面组(TSGR)**必在单元之后**（见「单元」模块）。

## 1. API 接口
| 项 | 内容 |
|---|---|
| 端点 | `/db/SECT` |
| 写入 | `PUT /db/SECT`，body = `{"Assign": {<id>: {截面定义}}}` |
| 回读 | `GET /db/SECT` → `{"SECT": {<id>: {…}}}` |
| 两种 SECTTYPE | `PSC`=设计截面（单一几何 `SECT_I`）/ `TAPERED`=变截面（两端几何 `SECT_I`+`SECT_J`）|

## 2. JSON 各字段含义
```
{
 "SECTTYPE": "PSC",              # PSC=设计截面 / TAPERED=变截面
 "SECT_NAME": "主梁支座截面",
 "SECT_BEFORE": {
   "OFFSET_PT": "CT",            # 截面参考点：CT=Center-Top(截面顶对齐节点)→变高靠梁底下凹
   "SHAPE": "NCE2",             # 截面类型(单箱多室2)；其它类型见截面库
   "USE_SHEAR_DEFORM": true,    # 计剪切变形
   "USE_WARPING_EFFECT": false, # 不计翘曲
   "USE_SYMMETRIC": true,       # 对称(→C=A、D=B)
   "PSC_OPT1": "POLYGON",
   "PSC_OPT2": "1",             # 室数(单室=1)
   "JOINT": [false, false],
   "SECT_I": {                  # PSC=该截面几何 / TAPERED=I端几何
     "vSIZE_PSC_A": [...11...], # 外轮廓；位映射见截面库
     "vSIZE_PSC_B": [...18...], # 内轮廓/壁厚；位映射见截面库
     "vSIZE_PSC_C": [...],      # 右外轮廓(对称=A)
     "vSIZE_PSC_D": [...],      # 右壁厚(对称=B)
     "SWIDTH": 16.0             # 桥面全宽
   }
   # —— TAPERED 额外 ——
   # "TYPE": 11,                # 11=NCE2(变截面里标类型)
   # "SECT_J": { …J端几何，结构同SECT_I… },
   # "Y_VAR": 1,                # 宽(y)变化次数：1=线性
   # "Z_VAR": 1                 # 高(z)变化次数：1=线性(等高变壁厚) / 2=抛物(变高,FCM梁底抛物线)
 }
 # 其余 WARPING_CHK_*/USE_WEB_THICK*/OFFSET_* 等：默认值，PUT 可省，MIDAS 自填
}
```
> **要点**：① `OFFSET_PT="CT"`——节点在截面**顶**、梁高向下生长（与边界虚拟支座 dZ=−梁高、钢束 PROFZ 约定一致）。② TAPERED 的 `SECT_I/SECT_J` **内嵌两端真实几何、非 ID 引用**。③ 等高两端→`Z_VAR=1`(线性变壁厚)；变高两端→`Z_VAR=2`(抛物变高)。

## 3. 映射与格式
**数据来源**：决策文档「设计截面」章的**截面参数映射表**（每母截面的完整 vSIZE，来自 `截面库/<类型>.md` 的位映射 + 图纸判读值）。
- **PSC**：`SECTTYPE="PSC"` + 只填 `SECT_I`（=该控制截面 vSIZE）。
- **TAPERED**：`SECTTYPE="TAPERED"` + `SECT_I`(I端) + `SECT_J`(J端) + `Y_VAR/Z_VAR` + `TYPE=11`。I/J 端几何 = 两端控制截面的 vSIZE（按单元方向 I→J）。
> **★vSIZE 单位 = 模型当前长度单位**：kN-m 模型填 m（梁高 5.2、SWIDTH 16.0）；N-mm 模型填 mm（5200、16000）。回读核对：`总高 = vSIZE_PSC_A[0]+[1]+[4]`。

## 4. 例子
**例桥**：变截面预应力混凝土连续箱梁 70+100+70 m（截面=单箱单室 NCE2；真实截面图见 [主桥箱梁横截面.png](../../assets/示例/变截面连续箱梁桥-FCM-NCE2/主桥箱梁横截面.png)：1-1 支座 / 2-2 跨中 / 3-3 边墩）。**7 母截面 = 3 PSC + 4 TAPERED**（由 `GET /db/SECT` API 实测）：

| id | 类型 | 名称 |
|---|---|---|
| 1/2/3 | PSC | 主梁支座截面 / 主梁跨中截面 / 边跨墩截面 |
| 4 | TAPERED | 边跨-跨中（S3→S2，等高 Z_VAR=1）|
| 5 | TAPERED | 跨中-支座（S2→S1，变高 Z_VAR=2）|
| 6 | TAPERED | 支座-跨中（S1→S2，变高 Z_VAR=2）|
| 7 | TAPERED | 跨中-边跨（S2→S3，等高 Z_VAR=1）|

vSIZE 取自 `截面库/单箱多室2-NCE2.md`（支座 A=`[0.2,0.6,0,0,5.2,4,0,0,0,4,0]`、B=`[0.3,0.4,0,0,0,0.3,1.2,1.1,1.2,0,0,0,0.3,0,0,0,0,0]`…）。

> **★单位起手设定、vSIZE 直接录入（核心准则 2）**：建模之初以 `PUT /db/UNIT` 将单位制设为 **kN-m**，vSIZE 即按 **m** 直接录入（梁高 5.2、SWIDTH 16），无需换算。本模块例子全程 kN-m。沿用既有模型时应先 `GET /db/UNIT` 核实：若为 N-mm，或以 `PUT /db/UNIT` 改回 kN-m，或按 mm = m×1000 录入。

**③ Python 驱动（从决策文档「设计截面」表批量建；`MidasAPI` 约定同「节点」模块）**
```python
def psc_geo(A, B, sw=16.0):                          # 对称→C=A、D=B
    return {"vSIZE_PSC_A": A, "vSIZE_PSC_B": B,
            "vSIZE_PSC_C": A, "vSIZE_PSC_D": B, "SWIDTH": sw}
COM = {"OFFSET_PT": "CT", "SHAPE": "NCE2", "USE_SHEAR_DEFORM": True,
       "USE_WARPING_EFFECT": False, "USE_SYMMETRIC": True,
       "PSC_OPT1": "POLYGON", "PSC_OPT2": "1", "JOINT": [False, False]}
assign = {}
for r in sect_rows:                                  # r: id/类型/名称/A,B(/AJ,BJ,Z_VAR)
    sb = dict(COM)
    if r["类型"] == "PSC":
        sb["SECT_I"] = psc_geo(r["A"], r["B"])
        assign[r["id"]] = {"SECTTYPE": "PSC", "SECT_NAME": r["名称"], "SECT_BEFORE": sb}
    else:                                            # TAPERED：内嵌两端真实几何
        sb.update({"TYPE": 11, "Y_VAR": 1, "Z_VAR": r["Z_VAR"]})
        sb["SECT_I"] = psc_geo(r["A"],  r["B"])      # I 端（单元方向起点）
        sb["SECT_J"] = psc_geo(r["AJ"], r["BJ"])     # J 端
        assign[r["id"]] = {"SECTTYPE": "TAPERED", "SECT_NAME": r["名称"], "SECT_BEFORE": sb}
MidasAPI("PUT", "/db/SECT", {"Assign": assign})
```
