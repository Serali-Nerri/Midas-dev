# 规范层总目 / 路由（规范引擎入口）

本目录 `reference/code/` 是 skill 的**规范层**，自包含。两层组织，职责分离：

| 层 | 文件 | 作用 |
|---|---|---|
| **定位索引层**（只记位置）| `jtg_d60_2015_index.md`、`jtg_3362_2018_index.md` | 主题/表/式/图 → 章条号 + PDF 页。轻量，不含数值。 |
| **取值层**（确定性数据）| `../code_tables.md` | 规范引擎消费的数值/公式；**每条引用索引锚点作出处**，按需从索引定位后填。 |
| 规范源 | `pdf/JTG D60—2015….pdf`、`pdf/JTG 3362—2018….pdf` | 扫描图像版；取值阶段定向 Read 对应 PDF 页核对。 |

> **铁律**：确定性的量查表/算公式，绝不靠 LLM 记忆。索引给「在哪」，取值层给「是多少」且可溯源。
> **分工**：**D60** 管荷载/车道/温度/组合（作用侧）；**3362** 管材料/预应力/构件设计与验算（抗力侧）。

## 使用约定

1. **查值流程**：建模量 → 路由表定位规范+索引 → 索引文件查精确 表/式 编号与 PDF 页 → 回 `pdf/` 对应页读数值 → 写入 `code_tables.md` 并注明出处。
2. **冲突处理**：官方示例（FCM 等）或既有参照模型与规范取值冲突时，**以规范为准**，并在 `code_tables.md` 记冲突日志。
3. **跨规范量**：温度梯度基数在 D60，效应公式在 3362 附录D；收缩徐变系数在 3362 附录C，作用组合在 D60——按路由表 1 取各自来源。
