## 3. 缺失/存疑与使用须知

- **编号复核**：本索引详细部分由 10 个 Sonnet worker 分段产出，协调者（Opus）在会话中断前**未及做整体编号复核**——编号以扫描原图为准，取确定性数值时务必回对应 PDF 页核对。
