## 4.3.1 车道荷载标准值 q_k / P_k　[JTG D60-2015 §4.3.1，PDF p.30-31]

公路-Ⅰ级（公路-Ⅱ级取 0.75 倍）：
- 均布荷载 **q_k = 10.5 kN/m**（§4.3.1 正文，全长满布）。
- 集中荷载 **P_k**（表 4.3.1-2，按计算跨径 L₀）：
  - L₀ ≤ 5 m：P_k = 180 kN
  - L₀ ≥ 50 m：**P_k = 360 kN**
  - 5 < L₀ < 50 m：线性内插 P_k = 180 + 4·(L₀ − 5)
- 计算**剪力**效应时，上述 P_k **× 1.2**（如主跨 360×1.2 = 432 kN）。
- 设计车道数（表 4.3.1-4）/横向折减（表 4.3.1-5）/纵向折减（表 4.3.1-6）见上文 3 张表。
- **走 MIDAS 中国规范引擎**：CODE=CHINA + 车辆 CH-CD，引擎按布载车道数自动施加横向折减，
  按跨径/基频算 q_k/P_k/冲击（建模操作见 `建模模块/移动荷载.md`、`建模模块/分析控制.md`）。

## 4.3.2 汽车荷载冲击系数 μ　[JTG D60-2015 §4.3.2，PDF p.33]

- μ = f(结构基频 f)，分段：f < 1.5Hz → μ=0.05；1.5 ≤ f ≤ 14Hz → μ=0.1767·ln f − 0.0157；f > 14Hz → μ=0.45。
- 填料厚 ≥ 0.5m 的拱桥/涵洞不计冲击。基频由 MIDAS 模态分析回代（引擎自动）。

## 温度作用　[JTG D60-2015 §4.3.12，PDF p.38-39]

- 整体（有效）温度（表4.3.12-2，混凝土桥面板混凝土桥，按气候分区）：最高 39℃；
  最低 严寒 −32 / 寒冷 −15 / 温热 −6(−1)℃。温度作用 = 有效温度 − 合龙温度。
- 竖向梯度温度基数（表4.3.12-3，正温差）：

  | 铺装 | T₁ (℃) | T₂ (℃) |
  |---|---|---|
  | 水泥混凝土铺装 | 25 | 6.7 |
  | 50mm 沥青 | 20 | 6.7 |
  | **100mm 沥青** | **14** | **5.5** |

- 梯度沿梁高：顶面 0~100mm 线性 T₁→T₂，100~400mm 线性 T₂→0（图4.3.12，A=300mm 当 H≥400mm）。
- 负温度梯度 = 正温差 × **(−0.5)**（→ 100mm沥青：−7 / −2.75℃）。

## 荷载组合系数　[JTG D60-2015 §4.1.5/§4.1.6，PDF p.23-25]

**承载能力极限状态-基本组合**（式4.1.5-1）：Sud = γ₀·[Σγ_Gi·G + γ_Q1·Q1 + ψc·Σγ_Qj·Qj]
- γ₀（结构重要性，表4.1.5-1）：一级 **1.1**，二级 1.0，三级 0.9。
- 永久作用分项 γ_Gi（表4.1.5-2，不利 / 有利）：

  | 永久作用 | 不利 | 有利 |
  |---|---|---|
  | 混凝土结构重力（含附加）| 1.2 | 1.0 |
  | 预加力 | 1.2 | 1.0 |
  | 混凝土收缩徐变 | 1.0 | 1.0 |
  | 基础变位（混凝土/圬工）| 0.5 | 0.5 |

- 汽车荷载 γ_Q1 = **1.4**（车道荷载；车辆荷载 1.8）。
- 其他可变（除汽车、风）γ_Qj = **1.4**，组合值系数 ψc = **0.75**；风 γ=1.1。
- γ_L（设计使用年限调整）= 1.0（按 JTG B01 取年限时）。

**正常使用极限状态**：
- 频遇组合（式4.1.6-1）：汽车 ψf1 = **0.7**；温度梯度 ψf = 0.8；人群 ψf = 1.0。
- 准永久组合（式4.1.6-2）：汽车 ψq = **0.4**；温度梯度 ψq = 0.8；人群 ψq = 0.4。
- 偶然组合（式4.1.5-3）：汽车 ψf1 = 0.7；风 ψf = 0.75；温度梯度 ψf = 0.8。

> 应用见 `fcm_box_jtg_model/add_live_load_and_combos.py` 的 `build_combos()`（每项注规范出处）。

## 验算限值（S10 验算引擎消费）　[JTG 3362-2018 §5 / §6.3 / §7]

> 抗力/限值层（**数值**）。验算**做法/数据通路/自算公式/超限补强**见 `验算指南.md`。
> **确定量回规范条文**；σ 取拉为正、压为负（与 MIDAS `BEAMSTRESSPSC` 一致）。
> 材料强度查上文「材料—混凝土」表：C50 fck=32.4/ftk=2.65、C40 fck=26.8/ftk=2.40 MPa；钢束 fpk=1860/fpd=1260。

### 正截面抗裂（受弯，§6.3.1 / §6.3.2，PDF p.66-67）
作用频遇组合下边缘法向拉应力 σst=Ms/W0、准永久组合 σlt=Ml/W0（式6.3.2-1/-2）。σpc=扣全部预应力损失后预加力在该边缘的预压应力（取正值，§6.1.6）。

| 构件类别 | 验算式 | 出处 |
|---|---|---|
| 全预应力·整体预制 | σst − 0.85·σpc ≤ 0 | 式(6.3.1-1) |
| **全预应力·分段浇筑/纵向分块（FCM 悬浇属此）** | **σst − 0.80·σpc ≤ 0** | 式(6.3.1-2) |
| A 类·频遇 | σst − σpc ≤ 0.7·ftk | 式(6.3.1-3) |
| A 类·准永久 | σlt − σpc ≤ 0 | 式(6.3.1-4) |
| B 类 | 结构自重作用下控制截面受拉边缘不得消压 | §6.3.1-3) |

> 跨径>100m 主梁宜按**全预应力**设计（§4.1.6）→ 本桥(130m 主跨)取 **式(6.3.1-2)**：净拉应力须 ≤ 0.80σpc 的"剩余"，
> 等价于 `σ_net(频遇) ≤ −0.20·σpc`（净应力须仍受压、压余 ≥ 0.20σpc）。

### 斜截面抗裂（主拉应力 σtp，§6.3.1-2/§6.3.3）
σtp 由频遇组合+预加力按莫尔圆算（式6.3.3-1）。**施工阶段**可直接取 `BEAMSTRESSPSC` 的 `Sig-Ps(Max)`（OPT_CS）；
**组合(频遇/标准)无 PSC 主应力**，须自算：重心轴 σcx=N/A、τ=V/Asz（N/V 取 `BEAMFORCE` 组合、A/Asz 取 `SECTIONALL`）→ σtp=σcx/2+√((σcx/2)²+τ²)。详 `验算指南.md`。

| 构件类别 | 限值 | 出处 |
|---|---|---|
| 全预应力·预制 | σtp ≤ 0.6·ftk | 式(6.3.1-5) |
| **全预应力·现浇（含预制拼装）** | **σtp ≤ 0.4·ftk** | 式(6.3.1-6) |
| A/B 类·预制 | σtp ≤ 0.7·ftk | 式(6.3.1-7) |
| A/B 类·现浇 | σtp ≤ 0.5·ftk | 式(6.3.1-8) |

### 持久状况使用阶段应力（§7.1，标准组合，PDF p.75-77）
作用取**标准值**，汽车计冲击（§7.1.1）。需"标准组合"工况（恒载+预应力+汽车(含冲击)+ψc·其他可变）。

| 验算 | 限值 | 出处 |
|---|---|---|
| 受压区混凝土最大压应力（全预/A类未开裂）σkc+σpt | ≤ 0.50·fck | 式(7.1.5-1) |
| 体内预应力钢绞线/钢丝拉应力 σpe+σp | ≤ 0.65·fpk | 式(7.1.5-2) |
| 预应力螺纹钢筋 σpe+σp | ≤ 0.75·fpk | 式(7.1.5-4) |
| **混凝土主压应力 σcp** | **≤ 0.6·fck** | 式(7.1.6-1) |

### 短暂状况/施工阶段应力（§7.2，PDF p.78-80）
作用取标准值、不计组合系数（§7.2.1）。f'ck/f'tk = 施工阶段龄期对应的强度（张拉时 ≥80%设计强度，§7.2.3）；
工程上常以设计强度近似（偏不利的略保守）。σ 取 `BEAMSTRESSPSC` OPT_CS 各阶段 `Sig-xx(Summation)`（拉 max / 压 min）。

| 验算（PSC 受弯，§7.2.8） | 限值 | 出处 |
|---|---|---|
| 截面边缘混凝土压应力 σ'cc | ≤ 0.70·f'ck | 式(7.2.8) |
| 截面边缘混凝土拉应力 σ'ct | ≤ 1.15·f'tk（且按拉应力配纵筋率 0.2~0.4%） | §7.2.8-2) |

> 本桥 C50 主梁常用派生限值(MPa)：0.50fck=16.2、0.6fck=19.44、0.70fck=22.68、1.15ftk=3.05、0.4ftk=1.06、0.65fpk=1209。
> 这些由引擎从本表 fck/ftk/fpk **乘系数算出**，不另存死值。

### 承载能力极限状态（§5）
正截面抗弯 γ0·Md ≤ Mu（式5.2.2/5.2.3）、斜截面抗剪 γ0·Vd ≤ Vcs+Vsb+Vpb（式5.2.9）。γ0=1.1（一级）。
- **抗弯**：可先算**顶束下限** Mu=Σ(过控制截面顶束 Ap)·fpd·保守内力臂(0.85h)——全预应力梁顶束下限通常即富余（普通钢筋仅增余量，
  符合"全预应力多由 SLS 控制"）。Ap/几何取 MIDAS `/db/TDNT`(面积)+`/db/TDNA`(过哪些单元/线形)。fpd=1260（表3.2.3-2）。
- **抗剪**：Vcs 显式含**箍筋配筋率**ρ_sv（式5.2.9），属设计输入；模型无箍筋时只出需求 γ0·Vd，待定箍筋方案后叠加（纯后处理）。
