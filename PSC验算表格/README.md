# PSC 验算表格（JTG）

本目录收录预应力混凝土（PSC）桥梁按 JTG 规范做验算与配筋估算时的 Excel 计算表格，共 15 张。既可独立手算使用，也可配合 `skills/midas-bridge-modeling` 技能第 ④⑤ 步（分析反算与验算微调）使用。

## 表格一览

### 持久状况（承载能力极限状态）

| 表格 | 用途 |
|---|---|
| `持久状况正截面抗弯验算.xlsx` | 正截面抗弯承载力 |
| `持久状况正截面抗剪验算.xlsx` | 正截面抗剪承载力 |
| `持久状况正截面抗压验算.xlsx` | 受压区混凝土应力 / 正截面抗压 |
| `持久状况正截面抗拉验算.xlsx` | 正截面抗拉（钢筋应力控制） |
| `持久状况抗扭验算.xlsx` | 抗扭承载力 |

### 施工阶段

| 表格 | 用途 |
|---|---|
| `施工阶段法向应力验算.xlsx` | 施工阶段截面法向应力（压/拉控制） |
| `预应力钢筋拉应力验算.xlsx` | 施工阶段预应力钢筋拉应力控制 |

### 使用阶段（正常使用极限状态）

| 表格 | 用途 |
|---|---|
| `使用阶段正截面抗裂验算.xlsx` | 正截面抗裂 |
| `使用阶段顶底板斜截面抗裂验算.xlsx` | 顶底板斜截面抗裂 |
| `使用阶段腹板斜截面抗裂验算.xlsx` | 腹板斜截面抗裂 |
| `使用阶段正截面压应力验算.xlsx` | 正截面混凝土压应力 |
| `使用阶段斜截面主压应力验算.xlsx` | 斜截面主压应力 |

### 配筋估算与构造

| 表格 | 用途 |
|---|---|
| `预应力钢筋用量估算.xlsx` | 预应力束量估算（首版配束） |
| `普通钢筋用量估算.xlsx` | 普通钢筋用量估算 |
| `最小配筋率验算.xlsx` | 最小配筋率构造检查 |

> 规范依据以各表内标注及 `skills/midas-bridge-modeling/reference/code/`（JTG D60 / JTG 3362）为准；表格公式仅供验算参考，关键结果请以规范条文复核。
